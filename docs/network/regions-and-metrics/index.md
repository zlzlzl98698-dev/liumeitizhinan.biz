faqs:
  - q: 测速图里写着平均速度 50 MB/s，这是不是就是 50 兆宽带？
    a: 不是！1 MB/s（兆字节/秒）等于 8 Mbps（兆比特/秒）。50 MB/s 等价于 400 Mbps 的带宽速率，相当于在四百兆宽带下跑满的速度。阅读任何测速图时务必看清后缀是大写 B（Bytes）还是小写 b（bits）。
  - q: 为什么香港节点测出来延迟只有 25ms，看 YouTube 极快，但我一用美国节点 150ms 也能看 4K？
    a: 物理延迟（ms）主要影响“点开网页瞬间、交互点击和建立连接的反应快慢”；而视频能否看 4K 流畅不缓冲，核心看“持续下载吞吐带宽（Mbps）与 0 丢包率”。只要美西节点单线程能稳定跑出 30 Mbps 以上且不丢包，除了首帧起播比香港慢零点几秒外，播放 4K 正片同样顺滑。
  - q: 节点列表里有很多“日本”“新加坡”“美国”节点，怎么一眼挑出最适合自己的？
    a: 按第一用途选：日常刷 YouTube、查资料和看港台字幕剧优先香港或日本；用 ChatGPT 和 Claude 首选美国或日本固定单节点；用 Gemini 重点关注实测通过的新加坡、马来西亚或合规美国节点；台湾节点适合台剧、B 站港澳台和动画疯。
  - q: 什么是晚高峰（Peak Hours）测试标准？为什么白天测出来的图不能全信？
    a: 中国大陆家庭与移动宽带的国际出口高峰期集中在每日 20:00–23:00（尤其是周五、周六晚）。白天 14:00 或凌晨 02:00 测试只能体现服务器物理性能上限，唯有晚高峰实测不丢包、不掉速才能说明日常好用。
  - q: 测速图上的 TLS RTT 和 HTTPS 延迟如果差出十几倍（比如 RTT 60ms，HTTPS 1200ms），代表什么？
    a: 代表您与机场中转入口握手上 TLS 的速度很快，但节点海外落地机向目标网站发起网页请求时非常缓慢或绕路（常见于特定跨网路由波动或海外出口拥塞，如 2026-08-19 河北联通测试中个别香港节点呈现的情况），实际浏览网页会有明显转圈停顿感。
  - q: 我自己的家宽只有 100Mbps 或 300Mbps，看机场测速图里那些 9Gbps 后端跑出来的 400MB/s 有用吗？
    a: 9Gbps 服务器后端测试展现的是“机场节点的极限承载冗余能力”（类似于高速公路有多少条车道），您家里宽带本身只有 300Mbps（最高约 37.5 MB/s）时，实际下载永远不会超过您自家物理宽带上限；但冗余越足的节点在晚高峰越不容易被其他用户挤慢。

# 热门节点地区特性与测速指标解析：如何科学选区与读懂测速图

**Answer-First 核心结论**：面对订阅列表里动辄五六十个不同国家编号的节点，既不要只无脑点延迟最低的香港，也不要被测速图上的高数字迷惑。选节点记住两条口诀：**① 看用途选地区——日常网页/4K 首选港日新，ChatGPT/Claude 选美日新（避开香港），Gemini 优先试新/马/合规美；② 看测速抓关键——分清 `1 MB/s = 8 Mbps`，重点看“单线程速度 + HTTPS 延迟 + 晚高峰 20:00–23:00 零丢包”，不拿白天 32 线程并发峰值当常态。**

## 二、彻底搞懂测速图上的五大关键指标（拒绝单位混淆）

### 1. 下载速度：`Mbps` 与 `MB/s` 的 8 倍转换关系
这是全网用户最容易看错的地方：
- **宽带运营商与 Speedtest 常用单位是 `Mbps`**（Megabits per second，兆比特每秒）；
- **Windows 文件下载与 MiaoKo/Clash 测速图常用单位是 `MB/s`**（Megabytes per second，兆字节每秒）。
- **换算表**：
  - `10 MB/s` = `80 Mbps`（百兆宽带级别，足以流畅看两路 4K 视频）；
  - `50 MB/s` = `400 Mbps`（接近半千兆宽带跑满）；
  - `125 MB/s` = `1000 Mbps`（千兆宽带理论极限）。

### 2. `TLS RTT` vs `HTTPS 延迟`（为什么只看节点列表绿色 ms 会被骗？）
许多机场订阅面板测出的延迟（如香港 28ms）仅仅是 TCP/TLS 握手耗时的 `RTT`。如果您在打开网页时觉得卡顿，往往是因为 **`HTTPS 延迟`（完成真实 HTTP 请求收到网页首字节的时间）** 已经飙升到 800–1500ms 以上。MiaoKo 测速图同时列出了 `TLS RTT` 与 `HTTPS 延迟` 两列，正是为了帮用户识别这种“伪低延迟”。

### 3. 单线程 vs 32 线程并发
`2026-08-11` 批次中 `MAI-TEST-BOT 2.0.0-dev` 采用 32 线程压测节点的最高总吞吐；而 `2026-08-19` 珠海联通 9Gbps 测速图则专门包含了 **单线程** 测试。个人日常看 4K 点播、加载大型网页图片与单文件下载，真正决定卡不卡的是**单线程持续速度**。

### 4. UDP NAT 类型（`FullCone` vs `RestrictedCone` vs `Unknown`）
- `FullCone`：NAT 穿透友好度最高，对部分外服游戏联机、P2P 语音视频通话有正面帮助；
- `Unknown`：常见于节点未开放对应 UDP 探测转发，或测试包丢包，但日常看网页、Netflix、ChatGPT（基于 TCP/HTTPS）通常不受影响。

### 5. `0B` / `KB` 级异常值留存意义
真实全量节点测速极少做到 60 个节点 100% 全绿无一故障。保留德国01 跌至 `43.08 KB/s`、美国02 出现 `1.60 KB/s` 等客观异常记录，能帮您提前知道避开具体故障编号节点。
