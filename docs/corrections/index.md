# 数据冲突记录与更正说明

在整理多份品牌清单与历史测试数据包的过程中，我们发现共有 **15 项数据冲突或待核实记录**。本站坚持不擅自拍脑袋删改任一原始来源，而是集中公开如下：

## 核心数据冲突清单

1. **光速云轻量版月流量冲突**：`主推光速云品牌信息.txt` 开篇摘要写为「年付折合约 8 元/月，59GB」，而同文档详表与 `推广机场品牌清单.txt` 均标为「¥99/年，69GB/月」。已并列标注。
2. **小明Cloud 2026-10-19 测速表雷同冲突**：小明Cloud 原文中的 2026-10-19 测速数据（HK 22ms/529Mbps 等）与光速云一字不差，疑似文档模板复制错误，本站不将其作为小明Cloud 独立测速结论。
3. **Firefly 与 Firefly 萤火虫别名及双链接**：主表 #8 `Firefly`（`code=2n7VURre`）与文末补充 `Firefly 萤火虫`（`code=jTp9wSgZ`）实为同一品牌实体，已合并归档并记录两条历史入口。
4. **优惠码多版本冲突**：暮光加速（`muguang5555` vs 介绍称无公开优惠码）、灵猫网络（`lmao888` vs `lingmao`）、一翻云（`yfy6666` vs `1FLYYUN`）、SOGO 云（`SOGO10000` vs `sss777`）、全球云（`qq88` vs `qqy7777`）、隐形人（`yxr888` vs `moon80`）均存在不同来源记录差异，已在各自详情页标注。
5. **推广链接格式异常**：云界线（两处 code 冲突且均缺少 `#/`）与环球梯（缺少 `#/`）的 URL 格式与常见前端路由不同，已添加跳转提示。
6. **2026-08-11 测速包核对项**：可信云截图底部未清晰显示完整日期（按批次暂记 `2026-08-11`，标为 `review-required`）；微风网络截图存在于压缩包中但未列入 `speedtest-manifest.json`。

## 更正处理原则与复核周期

- **复核触发机制**：当原始数据包文本与实测图片显示不一致（例如资料标 Trojan 而截图协议显 Shadowsocks），本站坚持在页面内显式展示双方差异，并由品牌评测页逐一解释工程成因，不做静默替换。
- **工程防呆审计**：每次站内构建前都会自动运行 `audit-brands.mjs`、`audit-conflicts.mjs` 与 `audit-affiliate-links.mjs`，自动重新核算冲突条目并输出更新至工程报告 `reports/DATA-CONFLICTS.md`。
