## 第一章：先拆解最关键的自相矛盾——“不支持第三方订阅”却写“支持软路由”？

审阅《推广机场品牌清单.txt》第 616–648 行 SOGO 云一节时，细心的读者会发现两段截然矛盾的说法：
- **第 616 与 648 行（明确两度写死限制）**：*“使用方式：专属客户端，下载登录即用（不提供订阅链接）”*、*“需要留意的是它不提供订阅链接，只能通过自研客户端使用，Clash、Shadowrocket 这类第三方客户端用不了。”*
- **第 622 行（核心特色条目却写着）**：*“自研客户端，支持 Windows、macOS、iOS、Android 与主流软路由。”*

### 为什么会出现这种冲突？用户该怎么信？
绝大多数软路由（OpenWrt OpenClash / PassWall2 / Nikki）并不可能去运行某个机场自己开发的图形 App，软路由接管的唯一通用标准方式就是**订阅链接或公开节点配置**。一旦服务端确定不提供订阅链接，普通 OpenWrt 就无从谈起（除非极罕见情况官方单独定制提供专属路由器插件安装包，但资料内未给出任何说明）。
- **本站保守审校结论**：绝不向用户虚构“肯定能上软路由”！在数据库与本评测里明确按 **“仅限官方专属客户端、不提供第三方订阅链接（Clash/Shadowrocket 不可用）”** 处理，若您确实计划上软路由，支付前务必进官网联系客服核实其自研端到底如何接路由器，否则直接改选 [光速云](/reviews/guangsu/) 或 [梯子云](/brands/tiziyun/)。
