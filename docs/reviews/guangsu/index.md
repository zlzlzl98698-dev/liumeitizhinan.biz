### 3.2 为什么资料写 VLESS，测试截图里却出现 Shadowsocks 和 AnyTLS？
很多仔细阅读技术参数的用户会发现一个现象：品牌说明文档强调 **VLESS 协议 + IEPL 专线**，然而本站保存的两组测速截图却暴露了更丰富的真实底层面貌：
1. 在 **2026-08-11** 快照及 **2026-08-19 长沙/广西/河北 62 节点版** 实测截图中，测试端解析出来的底层协议标记清一色显示为 **`Shadowsocks`**；
2. 而在同日 **2026-08-19 珠海联通 70 节点版** 专项实测中，节点协议明确显示为了 **`Vless` 与 `AnyTLS`**（并在节点名中出现了电信专属入口区分）。

这实际上揭示了许多成熟多协议机场的典型运行机制：面对不同阶段的防火墙特征审计、或者针对 Clash / v2rayN / 自研端等不同 Client User-Agent 下发不同模板时，服务端往往同时部署多套兼容端口（例如传统 SS2022/SS 与更新的抗审查 VLESS / AnyTLS 通道并行）。
- **对用户的直接启示**：千万不要再在电脑上用停更三年的旧版 Clash for Windows！为了保证当机场默认下发 AnyTLS 或 VLESS 新型传输协议时客户端能正常识别，必须保证桌面端跑在最新版 **Clash Verge Rev（Mihomo 核心）**、**FlClash** 或 **sing-box** 生态上（安装步骤参考 [CFW 迁移 Clash Verge Rev 指南](/guides/cfw-to-clash-verge/)）。

## 第四章：2026-08-19 五张 MiaoKo 三网实测原图逐帧深度复盘

相比那些只敢在官网发一张“局部截掉时间戳的百兆极速图”的机场，光速云在本站最大的评测含金量来自 **2026-08-19 保留下来的五张原生态 MiaoKo 测速原图**。这组图片没有把报错和丢包节点裁剪掉，让我们得以透视光速云在不同国内宽带运营商下的真实表现与短板。

### 4.1 跨三大运营商 2Gbps 对比（62/62 节点 · 6 线程 · Shadowsocks 模板）

#### 1. 长沙电信 2Gbps（`photo_2026-08-19_12-13-01.jpg`）
- **核心速度分布**：亚太主力节点整体表现非常整齐。其中 **日本09 平均速度达到 49.38 MB/s（峰值 55.72 MB/s）**，其余香港专线、新加坡与日本节点平均吞吐普遍稳定落在 **35–49 MB/s**（折合约 280–392 Mbps）。
- **延迟质感**：香港专线群 TLS RTT 低至 **20–31ms**，端到端 HTTPS 请求延迟也压在 **81–111ms** 的优良区间——这意味着在湖南及南方电信宽带环境下打开网页、看 4K 视频起播缓冲几乎没有可感知迟滞。
- **短板暴露**：一旦离开亚太专线圈，法国、英国、土耳其与德国等欧亚远距离节点速度大幅下降至 **4.32 MB/s – 15.31 MB/s**（其中德国01 最低 4.32 MB/s），勉强能看 1080p 或用于网页认证，不适合大文件拉取。

#### 2. 广西移动 2Gbps（`photo_2026-08-19_12-13-50.jpg`）
- **核心速度分布**：充分展现了移动宽带走 CMI 亚太通道的高并发特性。榜单前三名几乎并驾齐驱：**新加坡01 平均 53.12 MB/s、日本01 平均 52.89 MB/s、香港专线19 平均 52.04 MB/s**。
- **单节点故障暴露**：原图真实记录到 **德国01 在移动测试下突然跌至 43.08 KB/s**（相当于完全卡死不可用）。
- **流媒体附加状态（从同一测试表读出）**：台湾节点在 62 节点版下测试 **Disney+ 显示失败**，而台湾 Netflix 正常显示 `解锁(TW)`、YouTube 出现识别定位变为 `US` 的现象。

#### 3. 河北联通 2Gbps（`photo_2026-08-19_12-13-58.jpg`）
- **核心速度分布**：**新加坡01 平均 41.85 MB/s**、**台湾03 平均 37.49 MB/s**，主力节点带宽跑 4K 视频仍非常充裕。
- **极重要的工程警示——延迟指标背离**：图表中最值得北方联通用户反复研读的现象是：**部分香港专线节点的 TLS RTT 依然只有 65–85ms，看上去很绿很正常，然而它的实际 HTTPS 响应延迟却突然飙升到了 1200ms 以上**！这再次验证了我们在 [三网宽带晚高峰选线实操](/network/three-isp-routing/) 中强调的原则：单看 Ping / TCP 延迟表会骗人，北方联通用户在高峰期如果发现香港节点加载慢，果断切换至 **新加坡或台湾节点** 往往比死磕香港快得多。

### 4.2 珠海联通 9Gbps 单线程极限验证（70/70 节点 · VLESS / AnyTLS 模板）

#### 1. 订阅单线程真实极限速度与 NAT/UDP 特征（`photo_2026-08-19_12-20-10.jpg`）
相比 6 线程聚合跑分，**单线程测速更能直接反映你在浏览器看 YouTube 4K、单连接下载 GitHub 或刷流媒体时的“真功夫”**：
- **香港主力集群**：多条节点单线程平均跑出 **375–424 MB/s**（峰值冲到 **500.78 MB/s**），在 9Gbps 大口测试环境里充分释放了专线骨干的吞吐上限，说明单通道本身没有严苛的 10Mbps/30Mbps 隐性限速锁死；
- **美国跨洋集群**：跨太平洋节点在单线程下依然跑出了 **313–358 MB/s** 的优异吞吐，意味着哪怕看美区高码率 4K 电影或下载大型开发镜像（如 HuggingFace 模型权重）也不会明显拖慢；但同时图中也如实露出了 **美国02 单节点跌至 1.60 KB/s 的孤立异常点**，证明人工挑线与剔除病节点仍有必要；
- **新加坡与日本**：新加坡单线程跑在 **220–315 MB/s**，日本单线程约 **98–104 MB/s**（折合近 800 Mbps，应对 4K60fps 需求绰绰有余）；
- **UDP FullCone 与 QUIC / 游戏加速含义**：该次测试图右下角网络属性记录了多数主力节点的 UDP NAT 类型为 **FullCone（全锥形 NAT）**。FullCone 对重度使用 HTTP/3（QUIC，即 Chrome/YouTube 默认优先采用的低延迟传输层）、海外实时语音（Discord / Zoom / Teams）以及某些 P2P/联机主机游戏加速握手非常友好——相比于会频繁丢包的对称型 NAT（Symmetric NAT），FullCone 在建立高速连接时阻力明显更小。

#### 2. 基础流媒体与 AI 逐区真实表现（`photo_2026-08-19_12-18-40.jpg` 与 62 节点功能栏对照）

除了传统流媒体外，我们在仔细审视 `12-18-40.jpg` 时还注意到了两个颇有价值的小众平台实测信号：**TikTok 与 Bilibili**。
- **TikTok 地区标注出现 `ALISG` 等细粒度差异**：测试图显示香港节点虽然不少在 TikTok 上标注绿色可用，但部分后缀被识别归类为 `ALISG`（阿里云新加坡关联路由特征），日本、新加坡、美国和台湾也有部分节点通过、部分节点失败。**对于重度依赖纯净本土运营环境的跨境电商/TikTok 养号直播用户而言**，普通机场千人共享节点永远不能替代真正的独享原生住宅 IP（光速云针对此类场景另设了 ¥680/月企业独立 IP 定制档，普通套餐仅建议用来日常刷视频而不宜绑主力商业矩阵号）。

#### 4. 普通用户在购买后第一小时内建议做的 4 项“自检验证”

1. **第一分钟——先做本地“真延迟（URL Test）”筛选掉单点异常线**：点开 Clash Verge Rev 或 Shadowrocket，针对香港、新加坡、日本与美国各做一轮测速，把像样本里偶发掉到几 KB 或超时的冷门欧洲/个别异常节点（如曾经异常过的 `DE01` 或 `US02`）心里有数或通过筛选正则排除。
2. **第三分钟——用当地晚高峰时段实际打开一条 YouTube 4K60fps 测试片**：右键视频画面打开 `详细统计信息（Stats for nerds）`，看 `Connection Speed` 栏位稳定在 **25,000 Kbps** 以上且 `Network Activity` 无持续卡顿，再检查左上角 YouTube Logo 旁是否正常显示 `HK`/`JP`/`US`（确认没变成国内送中）。
3. **第六分钟——核对 Netflix 搜剧确认是完整片库还是自制剧**：在 Netflix 搜索框搜一部非原创热门版权剧（如《绝命毒师》或港台同期日漫），确认能看到搜索结果而非只出红标自制剧（参见 [Netflix 自制剧判定法](/ai/netflix-guide/)）。
4. **第十分钟——用无痕浏览器验证 ChatGPT 与 Gemini 分组路由是否打架**：测试 `AI-Lock` 美国/新加坡分组是否秒开 `chatgpt.com`，再单独测试新加坡/马来西亚节点能否正常打开 `gemini.google.com` 并收到完整流式回复；确认两路各自走通后再切换回日常使用，避免临时切来切去污染浏览器 Cookie。

## 第六章：客户端生态兼容度、三端实战分流与 TCO 费用核算

光速云在客户端支持上采取的是对用户最友好的 **“双轨并行”** 模式：新手可以从自研端无门槛起步，资深玩家和家庭软路由则可以完全脱离自研客户端，在第三方面板自由施展分流策略。

### 6.1 零配置路径：自研客户端的边界与适合场景
如果您只在单一的 Windows 办公电脑或安卓/iOS 手机上安装一款工具、期望“输入官网账号密码后点击连接”即完成查阅资料与看视频，光速云提供的自有客户端可以直接省去挑内核、辨认订阅格式（YAML vs Base64）、手动设定定时更新等全部初学摩擦。但需要清醒认识自研端的天花板：**它难以满足“同时让香港节点看 Netflix、美国节点固定跑 Claude、新加坡节点跑 Gemini”的精细域名级并发调度**。

### 6.2 为什么依然强烈建议进阶玩家导入第三方订阅？
正因为光速云没有像飞猫云、隐形人、SOGO 云那样把用户锁死在专属端里，一旦您把官网面板复制的通用订阅导入 **Clash Verge Rev**（桌面端）、**Shadowrocket**（iOS）或 **OpenWrt 软路由（OpenClash / Nikki / HomeProxy）**，您就能直接利用规则引擎避开它上面暴露的所有地区短板：

1. **桌面端 Clash Verge Rev（Windows / macOS / Linux）防泄漏与协议最优组合**
   - 导入通用订阅并确认核心切换至 **Mihomo（Clash.Meta）**，避免旧版已停更 Clash for Windows 无法识别 2026-08-19 实测中出现的 **VLESS / AnyTLS** 新式节点模板；
   - 务必在设置里安装 **Service Mode 服务模式并开启 TUN 虚拟网卡**，同时将系统或配置文件里的 `ipv6: false` 关闭（否则使用本地原生 IPv6 宽带时，OpenAI 和 Netflix 会直接抓到您真实内地 IPv6 地址导致报错）；
   - 将 **Netflix / YouTube 日常看剧组** 手动指向 `香港专线`、`日本` 或 `美国`；尽量避开在珠海联通测试中发生 YouTube 送中(CN) 的特定新/台节点；
   - 为 **OpenAI / Claude 写死独立的 `AI-Lock` 手选组**：利用全局扩展脚本把 `chatgpt.com`、`claude.ai`、`anthropic.com` 锁定到测试通过的某一条单一 `美国` 或 `新加坡` 节点上，既绕开“香港专线仅支持 OpenAI App”的网页限制，也根绝因自动 `url-test` 来回跳换 IP 导致的 Claude 封号（可直接套用 [Claude 防封号锁单节点完整 JS 脚本](/guides/claude-fixed-node-rules/)）；
   - **为 Google Gemini 划出 `SG / MY` 专属子组**：结合 2026-08-19 MiaoKo 实测发现，光速云在日/美/港/台节点对 Gemini 多显示失败，反而是 **新加坡、马来西亚、土耳其** 成功解锁。在规则首行单独把 `gemini.google.com` 与 `aistudio.google.com` 指去新加坡或马来西亚，就能在同一秒实现“ChatGPT 走美国、Gemini 走新加坡、Netflix 走香港、B站微信走直连”。

2. **移动端 iPhone / iPad（Shadowrocket 小火箭）配置关键**
   - 在 [Shadowrocket 添加订阅完整教程](/guides/shadowrocket-guide/) 指引下导入订阅并开启「打开时更新」；
   - 首页「全局路由」保持在 **`配置（Config）`**，确保国内常用软件直连不耗流量；
   - 若经常出差或在公司与家庭软路由之间切换，利用「按需连接」设置回家连接软路由 Wi-Fi 后自动休眠本机小火箭，出门走 5G 时自动拉起。

3. **家庭 OpenWrt 软路由部署注意项**
   - 当把光速云订阅导入 OpenClash 或 HomeProxy 时，考虑到前面提到的个别节点（如广西移动下的德国01 仅 43.08 KB/s、珠海联通下的美国02 仅 1.60 KB/s）出现过单点故障，**千万不要用包含全部冷门国家的大混合 `url-test` 自动池**；在策略组筛选正则中建议保留主力高质量亚美节点做主备切换，或者关闭欧亚小众节点的自动测速权重。

3. **多设备与家庭 OpenWrt 软路由用户**：非常契合。不限设备且 `1×` 计费适合家里软路由接管全屋设备；3 人家庭看 4K 视频直接建议看 **流光版（268GB）** 或 **量子版（568GB）**，别选小包。
