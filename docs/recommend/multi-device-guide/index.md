# 多设备与家庭用户怎么选机场？并发数、IP 限制与软路由防风控指南

**Answer-First 核心结论**：多设备个人（手机 + 电脑 + iPad ≥ 3 台）与家庭共享用户选机场，最核心的不是单纯看宣传写没写“不限设备”，而是同时确认 **三件事**：① **是否开放第三方订阅链接**（关系到 Apple TV、OpenWrt 软路由、Steam Deck 等终端能否接入）；② **同时在线 IP 容忍度与防滥用边界**（同家庭同 Wi-Fi 下多个设备一般算同 IP，跨地区多人合租易触发风控）；③ **中高流量档位单价与倍率**（推荐直接核算 250GB–600GB/月区间及 `1×` 倍率，避免月初买小包月底全家中途断网）。

---

## 一、看懂底层规则：“不限设备”不等于“不限同时在线 IP”

很多多端用户在购买套餐时容易混淆两个概念：**设备数量限制** 与 **公网 IP 并发限制**。

1. **为什么大多数正规机场允许“不限设备数”？**
   在 V2Board 等常见面板底层机制中，服务端很难直接读取客户端硬件 MAC 地址，最常采用的计量维度是**单位时间内的不同来源公网 IP 数（如每 5 分钟允许 3 个或 5 个独立公网 IP）**。
   - **单一用户多终端在同一家庭 Wi-Fi 下**：手机、MacBook、iPad、台式机共用同一个路由器公网出口，在机场后台日志中通常仅表现为 **1 个公网 IP**，即便您家里挂了 8 台设备也不会超限。
   - **同时出门开移动流量 + 家人留守家中 Wi-Fi**：此时同时产生 2 个公网 IP（家庭宽带 IP + 手机 5G IP）。若夫妻/父母各自在外通勤，最多也就 3–4 个独立 IP。
   - **跨宿舍/跨城市大合租**：若一个账号分发给七八位在不同城市、用不同基站的同学合租，瞬间出现 10+ 个跨省 ASN 来源 IP，即使写着“不限设备”，也很容易被风控系统判定为商业转售或账号泄露而触发限速或暂停服务。

> **选型警示**：如遇品牌写着“设备数以套餐而定”（如部分高价企业盘）或明确限制仅 2 台在线的微价小包，在手机+电脑+平板三端同时挂着代理时很容易踢掉前一台的连接。

## 二、多设备接入手册：通用订阅与软路由的关键优势

在决定品牌前，请先盘点您手里所有需要访问海外网络的设备清单。只要清单中出现以下任意一种设备，**请直接剔除不支持第三方订阅（纯专属客户端）的品牌**：

- **OpenWrt / ImmortalWrt 软路由 / 旁路由**：需要填入订阅 URL 或自建规则文件给 OpenClash / PassWall2 / Nikki / HomeProxy 拉取节点。
- **Apple TV / Android TV / 电视盒子**：Apple TV（tvOS）上使用 Stash、Shadowrocket（tvOS）或 Surge Apple TV 版，普遍依赖导入通用订阅链接，绝大部分机场的自研桌面/手机端并不会上架 tvOS 商店。
- **Linux 服务器 / 无桌面终端 / 开发容器**：常使用 `sing-box`、`mihomo` 或 `v2rayA` CLI 跑本地代理，仅认规范订阅配置。
- **需要同时控制多套独立规则的电脑**：比如您在公司电脑用 Clash Verge Rev + 局域网放行，在手机用 Shadowrocket，需要独立控制国内外直连与 AI 固定分流。

## 三、家庭与多端场景的流量估算标准

个人单用看 60GB–100GB 或许勉强够用，但多设备叠加后的消耗速度远超直觉，原因主要有三点：
1. **后台自动更新与多端重复缓存**：手机端预加载短视频、电脑系统/IDE 插件更新、iPad 自动同步海外相册或播客都会悄悄走掉流量。
2. **软路由未做好国内分流导致的误消耗**：如果家用路由器没有配置正确的 GeoSite/GeoIP 国内直连规则，全家看国内视频平台或百度网盘下载可能意外走掉代理节点。
3. **电视端大屏码率更高**：手机上看 1080p YouTube 每小时约 1.2–2GB，但客厅 65 寸电视或 4K 显示器播 Netflix/YouTube 4K 码率经常在 12–25Mbps 之间，每小时消耗 **5GB–11GB**。

建议按照使用角色直接核算：
- **单人多端（手机+Mac+iPad，日常 AI+1080p 视频为主）**：推荐 **130GB–200GB/月** 起步（例如 ¥20–¥34 档）。
- **二人同居或重度 4K 追剧/游戏更新**：推荐 **260GB–500GB/月** 档位，优先挑选明确标注 `1×` 倍率无虚标的品牌。
- **三人以上小工作室/软路由统一代理**：直接看 **500GB–1,000GB/月** 档位，同时留意购买前用软路由自带订阅测速确认稳定性，切勿让所有家庭成员都绑定到一个单一服务商上——保留一档 **不限时一次性流量包** 作为断流备用非常划算（如 [不限时流量包指南](/pricing/pay-as-you-go/) 所述）。

## 四、多设备并发与软路由防踩坑操作要点

1. **避免手机、电脑开“全局模式 (Global)”**：除非排查特殊故障，日常在 Clash Verge Rev、Shadowrocket 或 OpenClash 里请务必保持在 **规则模式（Rule）**，把中国大陆域名/IP 留在直连，既能保护带宽又能省下大量无效机场流量。
2. **区分“个人多端同订阅”与“多人共用同订阅的 AI 分组”**：如果家里有人在用 Claude Pro 或 ChatGPT 付费账号，切勿让家庭软路由开启 `url-test` 自动测速频繁切换出口地区，建议为 AI 域名单独划出固定的 `Select` 节点分组（具体写法见 [Claude 防封号锁单节点教程](/guides/claude-fixed-node-rules/)）。
3. **软路由统一拉取订阅后，手机在外开启移动网络别忘了关闭软路由重复接管冲突**：在家连 Wi-Fi 时如果路由器已经在透明代理，手机端关掉 Shadowrocket/FlClash 可以省电并减少二次代理损耗（或利用小火箭的「按需连接 / On Demand」自动识别家庭 Wi-Fi SSID 并自动关闭本地代理）。
4. **切勿为了图省事把订阅链接随便丢进陌生在线转换网页**：多端家庭往往会想把一份订阅同时转成 Shadowrocket、Surge 和 Clash 格式，但把包含认证 Token 的链接贴到不受信任的公共网站极易引发订阅被盗刷导致全家用量瞬间清零（详见 [订阅转换站泄露风险](/risk/subscription-converter-risk/)）。
