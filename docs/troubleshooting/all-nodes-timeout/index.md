# 所有机场节点突然超时（Timeout）怎么办？7 步区分本地网络故障与服务端停运

**Answer-First 核心结论**：面对客户端列表里“一排 60 多条节点全部变红 `Timeout` / 超时”的突发状况，**切忌第一时间急着重装软件或删订阅**。

请严格按照 **“先本地 → 再账号 → 后订阅 → 最终辨别服务端”** 的 7 步顺序排查（全程通常不到 5 分钟）：
- **①–③ 查本地与账号**：同步设备系统时间（消去 TLS 时间戳偏差）→ 检查本机网络与双 VPN 驱动冲突 → 登录官网核对套餐到期或超流量状态。
- **④–⑦ 更订阅与辨失联**：关掉代理直连更新订阅 → 核实内核兼容新协议 → 切手机 5G 热点排查 Wi-Fi/企业网拦截 → 若备用官网亦长期失联，再按应急替代预案止损。

## 一、快速自检判断表：你属于哪一类典型故障？

| 并发症状特征 | 最可能的真正原因 | 优先跳转对应解决步骤 |
|---|---|---|
| 双系统电脑（Windows+Mac/Linux）刚切回 Windows 就全红超时 | Windows 主板时间偏离了 8 小时时区或慢了超过 90 秒 | 立即执行 **第 1 步（校准系统时间）** |
| 所有节点全红，连机场官网进去一看流量条变满或已过期 | 月底重置日未到流量已提前耗尽，或月付套餐今天过期 | 立即执行 **第 3 步（核对账号与流量）** |
| 官网套餐正常，但节点列表还是上个月拉的 | 机场更换了国内中转入口域名或端口，老本地节点仍指向旧域名 | 立即执行 **第 4 步（更新订阅链接）** |
| 在公司/学校连 Wi-Fi 全超时，一换手机 5G 热点瞬间变绿 | 校园网或企业路由器拦截了代理常用非常规端口或阻断特征协议 | 立即执行 **第 6 步（网络隔离比对）** |
| 家用和 5G 全打不开官网，备用域名全失效，订阅返回 404/502 | 服务端出现大规模骨干故障或疑似服务停运 | 查看 **第 7 步与风险预案** |

## 二、逐项排除：7 步精准定位操作流程

### 第 1 步：强行校准设备系统时间（最高频隐藏杀手）
**原因**：VLESS、Trojan 与 VMess 协议高度依赖精确的 UTC 时间戳防重放攻击。哪怕你的电脑时间只比北京时间快了 2 分钟，海外服务器也会直接丢弃你的握手请求并保持静默，客户端测速即显示全军覆没 `Timeout`。
- **Windows 10/11**：右键任务栏右下角时间 →「调整日期和时间」→ 打开「自动设置时间」→ 往下滚动找到并点击 **「立即同步」**。
- **macOS**：打开「系统设置 → 通用 → 日期与时间」→ 确保开启「自动设置日期与时间」且时区在中国标准时间。
- **iOS / Android**：系统设置里打开「自动设置日期与时间」，若原本开着但时间明显偏差，可先关掉再重新打开触发重新对时。

### 第 2 步：排查“双代理/游戏加速器/公司 VPN”冲突
检查电脑托盘或手机状态栏里有没有同时开着：
- 网易 UU / 雷神等游戏加速器；
- 公司 Cisco AnyConnect / EasyConnect / WireGuard 内网 VPN；
- 另一款残留的 Clash / v2rayN / 官方机场客户端。
两个软件同时开着虚拟网卡（TUN）或争抢端口会立刻造成全部出站流量死锁超时。**全部退出其余软件后只留当前一个测试**。

### 第 3 步：确认官网账户有效期与剩余流量（及在线设备超限）
用系统自带浏览器（关闭代理状态）打开服务商官网或防失联发布页：
- 看清楚首页剩余流量是否已归零（回忆是否前晚开着 4K 或高倍率节点耗光了流量）；
- 看到期时间是否刚过；
- 看账户状态栏是否有「超设备限制」「被系统临时停用」告警（排查方式参考 [断流与账号异常排查](/troubleshooting/disconnect-and-quota/)）。

### 第 4 步：在“关闭本机代理开关”状态下更新一次订阅
当机场为了躲避阻断而更换国内中转服务器 IP 或端口时，您本地缓存在软件里的老配置还在敲一扇已经拆掉的门。
- **关键动作**：一定要先把 Clash Verge Rev 的「系统代理」和「TUN 模式」**全部临时关掉**（如果一直开着死节点再点更新，更新请求自己也会走死节点然后报错超时！）；
- 然后点击配置上的 **「更新订阅（Update）」**；
- 如果此时报错 `403`、`404`、`Connection refused` 或返回空节点，请立即配合查看 [订阅更新失败排查手册](/troubleshooting/subscription-update-failed/)。

### 第 5 步：核对客户端版本与协议兼容性
您是否还在使用停更三年的旧版 Clash for Windows 或远古版 v2rayN v4/v5？如果机场最近为了抗干扰把节点协议从老旧 SS/VMess 升级为 **VLESS-Reality、Hysteria 2 或 AnyTLS**（例如在 2026-08-19 实测截图中已经见到 VLESS/AnyTLS 节点混合下发），老客户端无法解析甚至会直接将节点屏蔽或全部握手失败。
- 请检查使用 [Clash Verge Rev（Mihomo 核心）](/clients/clash-verge-rev/)、[v2rayN 最新版](/clients/v2rayn/) 或 [Shadowrocket](/clients/shadowrocket/)。

### 第 6 步：切换手机 5G/4G 热点做环境对比
用笔记本连接手机开出的个人热点（或将手机关闭 Wi-Fi 只走移动数据）：
- 如果切换成蜂窝移动网络后全部节点立刻测速变绿、延迟恢复 40–200ms：说明服务商本身完全正常！故障出在您当前连着的 **家庭宽带路由器 DNS 污染、光猫防火墙等级过高或公司/校园网对特定海外端口协议进行了拦截**。此时可以尝试重启家庭光猫/路由器，或切换配置里的其他协议/端口节点。

### 第 7 步：判断是否为服务端严重故障或跑路停运
如果上述 1–6 步全部确认无误：系统时间分秒不差、套餐明明还有半年、官网主域与官方通知频道均已全线失联超过数天且多家不同运营商网络全部全红超时——这便符合外部服务异常的特征。切勿轻信陌生的“付费解封客服”诈骗信息，应依据 [确认机场是否停运与替代预案](/risk/alternatives/) 评估更换可靠备选，并吸取经验减少单一长周期压注风险（见 [避坑与跑路预警指南](/risk/avoid-pitfalls/)）。

## 三、修复成功如何验证？

在恢复其中一个环节后，切勿只看一次列表变绿就结束，请做两步验证：
1. 对港、日、新三个不同地区的各一条主力节点依次点击单节点 URL Test，确认延迟稳定在 `40–300ms` 而非随机闪绿；
2. 用浏览器访问一条非缓存的外部测试页面（如 Google 搜索任意今日新词或加载一条 YouTube 视频）确认数据下行流持续走通。
