# 网络连接成功但无法访问网页排查

**Answer-First 核心结论**：客户端显示“已连接”且节点延迟正常，浏览器却报错 **`ERR_PROXY_CONNECTION_FAILED`** 或 **`ERR_CONNECTION_REFUSED`**，绝大多数并非节点失效，而是 **本地端口错位、浏览器扩展抢占代理、策略组误选 `DIRECT/REJECT`，或流量根本未进入客户端内核**。

请按以下三步快速打通本地转发链路：
- **① 核对本地端口与扩展**：停用 SwitchyOmega 等浏览器代理插件，重开一次“系统代理”刷新监听端口。
- **② 检查分流模式与策略组**：确认主策略组选在有效节点，而非 `DIRECT`、`REJECT` 或误开的 `Global` 死节点。
- **③ 用连接日志和 TUN 兜底**：观察客户端「Connections」面板是否有流量进入，无流量时直接改用 TUN 模式测试。

## 一、代理已连接却无法上网：10 秒症状定位矩阵

| 症状现象 | 本质原因 | 优先处理方向 |
|---|---|---|
| 浏览器提示 `ERR_PROXY_CONNECTION_FAILED` 或代理无响应 | 系统代理或浏览器扩展指向了旧软件的失效端口号 | 停用浏览器代理扩展，重开系统代理刷新端口 |
| 报错 `ERR_CONNECTION_TIMED_OUT`，客户端连接日志里无任何记录 | 流量绕过了系统代理直接直连，或浏览器启用了冲突安全 DNS | 开启客户端 TUN 模式接管，检查浏览器代理设置 |
| 客户端连接日志有记录，但访问外网全部显示走了 `DIRECT` | 策略组被切到了 `DIRECT`，或订阅配置规则损坏/为空 | 检查「代理」面板策略组选中状态并更新订阅 |
| 提示 `DNS_PROBE_FINISHED_NXDOMAIN` 或所有域名均解析超时 | 本地 DNS 配置失效或残留，未正确完成域名解析 | 转至 [DNS 解析错误排查](/troubleshooting/dns-resolution-error/) |

## 二、代理已连接却无法上网：分步骤排查与修复操作

### 1. 排除浏览器扩展抢占与核对本地端口
1. **停用独立代理扩展**：打开 Chrome / Edge 扩展管理页面（`edge://extensions`），暂时关闭 **SwitchyOmega、ZeroOmega** 或其他浏览器 VPN 插件，让浏览器默认直接跟随操作系统代理设置；
2. **核对并刷新系统代理端口**：
   - 在 [Clash Verge Rev](/clients/clash-verge-rev/)（默认混合端口通常为 `7897`）或 [v2rayN](/clients/v2rayn/)（默认 HTTP 端口通常为 `10809`）主界面，**先关闭「系统代理」开关，等待 2 秒后再重新打开**，让软件把正确端口重新写入系统设置；
   - Windows 用户可按 `Win + I` →「网络和 Internet → 代理」检查“使用代理服务器”里的地址是否为 `127.0.0.1` 且端口号与客户端主界面显示的完全一致。

### 2. 检查策略组、运行模式与订阅完整性
1. 进入客户端「代理」页面，确认顶部模式为 **规则（Rule）**，不要误点成全直连（Direct）；
2. 点开主策略组（如 `节点选择` / `Proxy`）及子分组，确认当前高亮选中的是一条**延迟正常的具体海外节点**，而不是 `DIRECT` 或 `REJECT`；
3. 检查节点列表数量是否正常：如果订阅里只剩下一两条信息提示节点（如“套餐已到期”或“更新订阅”），说明配置文件本身无可用节点，请查看 [订阅更新失败排查](/troubleshooting/subscription-update-failed/)。

### 3. 用连接日志诊断并开启 TUN 模式兜底
- 打开客户端左侧的 **「连接（Connections）」** 或 **「日志（Logs）」** 面板，同时在浏览器刷新 `https://www.google.com`；
- **如果列表完全没有新请求跳出**：说明系统代理设置被操作系统或安全软件拦截未生效。直接按 [TUN 与 DNS 防泄漏配置](/guides/tun-and-dns/) 在客户端开启 **TUN 模式**，绕过传统端口机制直接由虚拟网卡接管全机流量；
- **如果列表显示目标域名命中了 `Proxy` 却依然超时**：说明问题在服务端节点本身，请转至 [部分节点超时排查](/troubleshooting/partial-nodes-timeout/) 或 [节点全部超时排查](/troubleshooting/all-nodes-timeout/)。

## 三、代理已连接却无法上网：恢复验收标准

- 刷新 Google 或 YouTube 页面时，客户端「连接（Connections）」面板实时滚出对应域名请求且规则列显示命中代理节点；
- 浏览器地址栏不再出现 `ERR_PROXY_CONNECTION_FAILED`，海外页面 2 秒内完成加载，同时国内网站依然保持流畅直连。
