# 频繁掉线与账号套餐异常排查

**Answer-First 核心结论**：使用中出现 **每隔几分钟断流重连、闲置时流量莫名暴涨，或节点突然全部失效**，根源通常在于 **订阅链接泄露触发并发超限、误用高倍率节点、全局模式下后台软件偷跑流量，或手机系统省电策略杀死了后台**。

排查与止损请立刻按以下三步执行：
- **① 查官网流量与设备记录**：先核对今日消耗与剩余有效期，发现异常并发立刻重置订阅链接与密码。
- **② 止住偷跑与高倍率消耗**：切回 `Rule（规则）` 模式避开 Steam/系统更新，核对节点名称里的 `1x / 3x` 倍率标记。
- **③ 保活手机后台与稳态连接**：安卓关电池优化、iOS 开按需连接，桌面端关闭频繁自动跳转。

## 一、节点断流与流量额度超限：10 秒症状定位矩阵

| 症状现象 | 本质原因 | 优先处理方向 |
|---|---|---|
| 闲置或只刷网页，流量却以每小时数 GB 速度暴跌 | 错开 `Global` 导致网盘/更新走代理、误连高倍率节点或订阅泄露 | 切回 `Rule` 模式，换 `1x` 节点，官网重置订阅链接 |
| 每隔 3–5 分钟规律性断流重连，刷新又好 | 并发设备/IP 数超过套餐限制，或客户端在自动频繁切换节点 | 排查在线设备数，关闭 `url-test` 改用手动固定节点 |
| 手机亮屏正常，锁屏熄屏几分钟后彻底断网 | 安卓电池优化杀后台，或 iOS 未开启「按需连接」 | 将客户端加入电池白名单，iOS 启用按需连接规则 |
| 订阅里所有节点突然在同一时刻全部超时不可用 | 套餐流量已耗尽归零、到期未续费，或服务端更换了订阅地址 | 登录官网核对套餐余量与公告，更新或重置订阅 |

## 二、分步骤排查与止损操作

### 1. 登录服务商后台核对异常记录并止损
1. 打开服务商官网仪表盘，重点核对 **「剩余流量」、「套餐到期时间」与「最近使用日志 / 在线设备 IP」**；
2. 若发现自己未使用的时段出现大量消耗，或存在陌生地区的连接记录，**立即点击官网后台的「重置订阅链接 / 订阅 UUID」并修改账户密码**（仅改登录密码不会作废旧订阅！），随后删除本地旧订阅并导入新链接；
3. 检查账号是否超出了套餐允许的同时在线设备数或 IP 数（家庭多设备建议参考 [多设备协同方案](/guides/multi-device-router/)）。

### 2. 排除高倍率节点与后台偷跑流量
- **识别倍率标记**：许多机场的高速专线、家宽或稀缺解锁节点会在名称中标注倍率（如 `2x`、`3x`、`5x`），用 `5x` 节点看 1 小时 4K 视频相当于直接扣除 25–40GB 套餐额度。日常刷视频请优先选择标注 **`1x` 或 `0.5x`** 的节点（详见 [流量计算与倍率规则](/pricing/traffic-and-multiplier/)）；
- **杜绝 `Global` 全局模式偷跑**：确保 [Clash Verge Rev](/clients/clash-verge-rev/) / [v2rayN](/clients/v2rayn/) 处于 **`Rule（规则）`** 模式，防止 Windows Update、macOS 系统更新、Steam/Epic 游戏下载、百度网盘或 OneDrive 后台上传悄悄跑完代理额度。

### 3. 修复手机端后台被杀与桌面频繁重连
- **Android 端（v2rayNG / Clash Meta / FlClash）**：进入手机「系统设置 → 应用管理 → 电池」设置为 **「无限制（不优化）」**，并在多任务视图中下拉锁住客户端卡片，防止锁屏清内存；
- **iOS 端（Shadowrocket）**：进入 [Shadowrocket](/guides/shadowrocket-guide/) 底部「设置 → 按需连接」，开启 **按需连接** 并配置「始终开启」规则，同时避免在「蜂窝/Wi-Fi」切换瞬间触发系统断开（参考 [Wi-Fi 与蜂窝网络排查](/troubleshooting/wifi-vs-cellular/)）；
- **桌面端**：关闭不必要的 `url-test` 高频探测，将常用策略组改为 `Select` 手动固定节点。

## 三、节点断流与流量额度超限：恢复验收标准

- 关闭海外页面让电脑或手机空闲挂机 30 分钟后，观察客户端统计面板与官网后台流量增长接近于 0；
- 连续观看长视频或进行长达 1 小时的在线语音/AI 对话，中间不再出现无故断开重连或节点突然跳变。
