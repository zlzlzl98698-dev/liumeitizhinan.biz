# Netflix M7111-5059 代理报错与“只显示自制剧”全面排查步骤

**Answer-First 核心结论**：Netflix 弹出 **`M7111-5059` / `E114` / `N8156-6003`（检测到代理）** 或退化成 **“仅显示自制剧”**，本质是 **Netflix 判定当前出口 IP 属于机房代理，或察觉 DNS/IPv6 与代理归属国自相矛盾**。

正确处置不是反复点重播，而是严格走完以下 **4 步闭环**：
- **①–② 辨别状态与堵泄漏**：先用《绝命毒师》辨别节点当前解锁状态 → 确保开启客户端 TUN/配置模式并禁用 IPv6 泄漏。
- **③–④ 换区与清缓存**：换至明确支持版权解锁的新节点 → 彻底清理浏览器 Cookie 或强杀 App 后台重进。

## 一、第一步：10 秒确诊你的节点处于哪种拦截级别

| 现象特征 | Netflix 后台给此 IP 的风控评级 | 解决重点 |
|---|---|---|
| 点击播放直接跳出红色/白色弹窗：**`M7111-5059` 或 `E114`（使用解锁器或代理）** | **高危严厉封禁（Hard Block）** | **必须更换纯净节点** + 彻底排查本机 IPv6 与 DNS 泄漏 + 清缓存 |
| **不报错**，能正常播《怪奇物语》《鱿鱼游戏》，但**搜索不到《Breaking Bad》《Friends》及热播日漫** | **软屏蔽降级（Originals Only）** | 当前机场 IP 被判为非原生数据中心段，需换去带版权解锁能力的节点地区 |
| 报错 **`E100`、`M7353`、`NSES-500`** 等黑屏、无法加载组件 | **多为 DRM 硬件认证、系统时间或本地网络卡死** | 转至 [**Netflix 无法播放与黑屏排查 →**](/troubleshooting/netflix-playback-error/) |

## 二、4 步彻底解决代理报错与自制剧降级

### 第 1 步：堵死本机 IPv6 泄漏与非代理 DNS 解析（最容易被忽视！）
很多时候明明机场提供的节点本身能完美解锁全片库，可你自己打开却秒报 `M7111-5059`：
1. **关闭本机/客户端 IPv6**：Netflix 服务端双栈监听 IPv4 与 IPv6。如果客户端只代理 IPv4，一旦宽带下发了国内 IPv6，Netflix 会同一秒看到“美国 IPv4 + 北京移动 IPv6”或“两条完全不同来源隧道”，当场报错拦截！请在 Clash Verge Rev 设置禁用 `ipv6: false`，或在物理网卡属性临时取消勾选 IPv6（详见 [IPv6 泄漏错误解决指南](/troubleshooting/ipv6-leak-error/)）。
2. **开启 Fake-IP 与 TUN 虚拟网卡接管**：保证浏览器、Windows Edge、或桌面端应用发送的 DNS 请求全部封装通过海外代理节点就地解析，而非先由中国内地公共 DNS 解析返回异常记录（操作见 [TUN 与 DNS 防泄漏配置](/guides/tun-and-dns/)）。

### 第 2 步：正确切换节点，避开已被批量标黑的节点号
1. 请务必注意：**并不是同一个机场所有叫“香港”的节点解锁状态都一模一样**！当 `香港01` 突然出现仅自制剧或报错时，尝试切往 `香港03`、`新加坡01` 或 `日本02`、`美国` 节点测试。
2. 如果在支持分流的客户端里，请确保您是在 `Netflix / Streaming` 分组（或者全局默认主代理组）切换的节点，而非切错了毫不相干的分组。
3. 核对机场是否具备实测解锁参考（例如在 [光速云实测分析](/reviews/guangsu/) 中展示的港/台/日/新/美节点流媒体分组测试差异，记住动态风控会随时间演变，以当天本地复测为准）。

### 第 3 步：彻底强杀重启客户端与清理浏览器会话缓存（换节点后最关键！）
**切勿在报错画面下直接切了节点然后原地按播放键！** Netflix 会维持一条已经绑定旧黑名单状态的长连接和 Cookie：
- **电脑网页端（Edge / Safari）**：换好新节点后，关闭 Netflix 标签页 → 清除浏览器的 `netflix.com` 与 `nflxvideo.net` 站点 Cookie（或用无痕/隐私模式全新打开验证）；
- **手机端（iPhone / Android App）**：换完新节点后，上划彻底从后台杀掉 Netflix App（Android 可进系统应用信息点「强行停止」+「清除缓存」但别轻易点清除全部数据免得重登），等待 5 秒再重新启动 App。

### 第 4 步：检查账号自身“限制区域”与移动/家庭同户提示
极少数情况下弹出地区受限并非节点 IP 被封，而是您购买的**低价拼车账号本身被锁区限制**：
- 例如某些土耳其区（TR）、巴西区（BR）新开账号前 30 天带有 **Geo-lock 地理锁**，只能用对应归属地或允许跨区节点访问，用香港或日本节点登录就会报错无法在当前地区观看。购号时务必问清卖家是否已完成首月区域解绑。
