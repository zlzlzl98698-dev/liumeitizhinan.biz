faqs:
  - q: 传统商业 VPN 和代理机场（Clash/Shadowrocket）本质上有什么区别？
    a: 传统商业 VPN 多基于 WireGuard、OpenVPN 或 IKEv2 构建整机全流量加密隧道，优点是隐私防护与一键傻瓜操作，缺点是在跨境公网直连下晚高峰易拥堵且国内网站易被一起绕远路；而代理机场配合 Clash/Shadowrocket 等客户端采用 VLESS/Trojan/Shadowsocks/Hysteria 2 协议与国内直连+海外代理规则分流，通常通过 BGP 中转或 IEPL/IPLC 专线改善跨境吞吐，更适合追流媒体和用 AI。
  - q: 为什么手机开启 Clash 或 Shadowrocket 时，状态栏也会显示“VPN”图标？
    a: 这是移动操作系统（iOS NEPacketTunnelProvider 与 Android VpnService）的系统级流量接管接口机制。无论底层使用的是 WireGuard 还是 VLESS/Mihomo 分流引擎，只要通过虚拟网卡接管全机流量，系统都会统一在顶部状态栏显示 VPN 标志，不代表它使用的是传统 VPN 协议。
  - q: 免费 VPN 到底能不能用？有哪些真实限制与风险？
    a: 极少数正规海外商业 VPN 提供的免费档位（如有限流量的测试版）可用于临时应急，但通常限制节点国家（无法自选日本/新加坡）、限速严重且几乎被 Netflix 和 ChatGPT 屏蔽。而网络上来源不明的“永久无限免费 VPN”则存在极大风险：可能通过注入广告、记录明文浏览行为、甚至将用户手机带宽转售为住宅代理出口（Botnet 节点）来牟利，严禁用于网银或重要主账号登录。
  - q: 网游加速器（如加速 Steam、PS5、APEX 的加速器）能用来看 Netflix 或上 ChatGPT 吗？
    a: 通常不能。网游加速器在技术上针对特定游戏服务器进程与 UDP 战网端口做专有路由转发，不向浏览器提供通用 HTTP/SOCKS5 代理接口，也不负责解锁流媒体版权库或 AI 网页认证域名。反之，普通机场也并非专门针对游戏 UDP 极低抖动优化（除非个别节点为 FullCone NAT 且线路极稳）。
  - q: Windows / macOS 和 Android / iOS 选 VPN 或代理工具有什么系统差异？
    a: iOS 生态封闭，所有代理工具（Shadowrocket、Stash、Quantumult X、Surge 5）均需从非中国大陆区 App Store 获取且多为付费买断应用；Android 允许直接安装 GitHub 官方签名的开源 APK（如 v2rayNG、FlClash、Hiddify），自由度高但需严防 Google Play 仿冒包；Windows 和 macOS 桌面端则要重点关注“系统代理 vs TUN 模式”切换，且 macOS 必须区分 Intel 与 Apple Silicon 架构安装包。
  - q: 电脑上同时开了游戏加速器和 Clash/VPN 为什么会全部断网？
    a: 游戏加速器与代理软件的 TUN 模式都会在操作系统层安装虚拟网卡并接管默认路由表与 DNS。两者同时开启会产生路由环路或网卡权重冲突，导致所有流量无出口可走。日常使用时应当二选一开启，切换前彻底退出另一方。
  - q: 为什么很多人说“手机 VPN 连上了但看剧卡顿”？
    a: 常见有三点原因：① 用了直连公网的传统 VPN，晚高峰跨境出口丢包；② 开了全局模式导致国内视频或后台同步抢占隧道带宽；③ 选了物理距离太远的欧美节点看 4K 视频。按平台需求改用具备亚太近端优化线路的规则分流方案通常能明显改善。
  - q: 隐私和安全上，VPN 宣传的“零日志（No-Logs）”可信吗？
    a: 对任何网络代理或商业 VPN 而言，服务商在技术上都能看到连接发起源 IP 与出口目标元数据（除端到端 HTTPS 加密载荷内容外）。真正有价值的不是口头口号，而是尽量做到：日常使用主流 HTTPS 网站、不随意安装未知第三方根证书、重要金融与政务操作走直连而不进陌生代理通道。
  - q: 苹果手机在国区 App Store 搜不到好用代理或海外 VPN 软件怎么办？
    a: 受地区上架政策影响，主流规则代理软件与国际商业 VPN 均未在中国大陆区 App Store 上架，需要自行注册或切换非大陆区 Apple ID 登录 App Store 下载。切勿在手机系统顶部的 iCloud 设置中登录陌生人提供的共享账号，防止设备被远程锁定。
  - q: 如果我既需要偶尔打外服联机游戏，又需要看 Netflix 和用 ChatGPT，怎么搭配最省钱？
    a: 最务实的组合是：游戏联机继续使用几十元/月的正规网游加速器（保证游戏进程路由稳定、不误封号）；流媒体与 AI 工作流单独配置一套支持规则分流的服务（如支持第三方订阅的月付专线机场 + Clash Verge Rev/Shadowrocket），需要打游戏时关闭代理软件即可，互不干扰。

# VPN 与加速器专题：技术边界、免费风险与全平台连接选型指南

**Answer-First 核心结论**：虽然大众在搜索习惯上常把所有跨区联网软件统称为“VPN”，但在实际产品形态与底层技术上，**传统商业 VPN、代理机场（配合 Clash/Shadowrocket 等客户端）以及网游加速器**是三类定位截然不同的工具。**传统 VPN 擅长一键全机加密隧道与海外本土隐私保护；代理机场 + 第三方客户端擅长国内直连与海外流媒体/AI 的精细规则分流及跨境抗拥堵传输；网游加速器则专攻外服游戏 UDP 端口低抖动转发。** 千万不要拿游戏加速器去查 ChatGPT，也不要用免费公网 VPN 去长期硬扛晚高峰 Netflix 4K。

> **技术边界与声明**：本专题依据可靠技术协议文档与 [客户端软件数据库](/clients/)（`data/clients.json`）编写，旨在帮助用户厘清产品类别差异、免费工具隐患与不同系统（Windows/macOS/Android/iOS）选型逻辑，不把三类不同产品混为一谈。

## 二、VPN 和代理工具的底层技术差异详解

很多用户感到困惑：为什么同样在手机右上角显示一个 `VPN` 小图标，传统 VPN 连上去有时打不开国内微信付款码，而配置好规则的代理客户端却可以一边秒开淘宝微信、一边流畅看 4K YouTube？差异就在以下四个底层环节：

### 1. 数据包封装层与系统接口机制
- **传统 VPN（L3 网络层全隧道）**：以 WireGuard 或 OpenVPN 为代表，它在设备建立虚拟网卡后，默认把操作系统发出的几乎全部 IP 层数据包（包含淘宝、银行 App、公司内网、甚至局域网广播）统一打包发往远端 VPN 服务器。这种机制的初衷是“当用户在公共咖啡厅 Wi-Fi 上网时，保护所有出站流量不被旁路嗅探”，而不是为了“按网站国家自动走不同路由”。
- **现代代理客户端（L4/L7 应用与规则分流层）**：Clash Verge Rev (Mihomo)、v2rayN (Xray)、Shadowrocket 与 sing-box 等客户端虽然在开启 TUN 模式或手机端 `VpnService` 时同样借助系统虚拟网卡接管流量，但在内核内部会第一时间读取**规则引擎（GeoIP + Geosite + 域名列表）**。凡是命中中国大陆直连清单的请求，直接由本地物理网卡发送（`DIRECT`）；只有命中海外列表的流量才经过加密协议发往海外落地服务器。

### 2. 协议特征与跨境链路传输差异
传统的 OpenVPN（TCP/UDP 1194 等）与 WireGuard（固定头部特征明显的 UDP 握手）在跨境公网链路中识别特征非常明显，在晚高峰或者特定骨干网 QoS 策略下极易遭到丢包限速甚至直接阻断握手。而现代代理生态普遍结合 **国内多线 BGP 中转 / IEPL 内网专线** 与 **TLS 伪装协议（如 VLESS-Reality、Trojan、AnyTLS）或抗丢包 QUIC 改进协议（Hysteria 2）**，从而在晚高峰能够维持更高的单线程吞吐。

### 3. 出口 IP 生态与平台风控差异
国际知名商业 VPN 的服务器 IP 段高度公开透明（几乎全部挂载在大型数据中心托管商名下），因此 Netflix、Disney+、Hulu、ChatGPT 与 Claude 的风控库长期对知名商业 VPN 出口 IP 进行批量拦截，用户往往需要频繁在 App 里“碰运气”换城市。而在代理机场体系中，许多服务商专门针对亚太用户提供了支持流媒体/AI 的特定落地机房或原生出口，虽然同样不能承诺永久 100% 解锁（参见[AI 与流媒体实测标准](/ai/)），但在地区可选密度与分流颗粒度上具有更大调整空间。

## 三、免费 VPN 的真实限制与不可忽视的安全隐患

在搜索引擎输入“免费 VPN”“手机免费加速器”时，排在前列的往往是两类截然不同但同样存在巨大隐患的渠道：

### 1. 正规商业 VPN 的“免费限额版”有哪些限制？
极少数合规海外商业厂商为了吸引付费转化，确实提供永久免费的基础档位，但通常会强制施加以下限制以控制带宽成本：
- **无法自选节点国家**：由系统随机分配欧美拥挤节点，用户往往连日本、香港、新加坡都选不了；
- **严格流媒体与 P2P 屏蔽**：免费档端口与 IP 明确禁止 Netflix、Disney+ 或 BT 下载；
- **单月流量极低（常见 2GB–10GB/月）或限速**：打开几段 1080p 视频即耗尽，且登录网页版 ChatGPT、Claude 极易因共享人数过多触发 Cloudflare 循环人机验证。

### 2. 来路不明“破解版 / 无限永久免费 VPN”的四大安全风险
如果一款宣称“不限流量、永久免费、高速看 4K、免注册直接连”的软件来自贴吧网盘、未知网页广告或非官方修改站点，强烈建议您保持高度警惕：
1. **将您的设备变成“免费住宅代理肉鸡”**：部分免费 VPN 的真实商业模式是在后台静默共享用户的家庭宽带 IP 供他人发起爬虫或攻击请求，导致您自己的宽带被各大网站拉黑甚至引发法律合规风险；
2. **诱导安装自签根证书与流量监听**：对未经加密或被中间人解密的 HTTP 请求注入恶意广告脚本、劫持搜索引擎结果或窃取网页表单 Cookie；
3. **捆绑恶意 SDK 与木马后门**：尤其在 Android 侧载渠道，修改版客户端极易内置静默读取通讯录、剪贴板（窃取加密货币钱包地址）或后台跑流量的隐藏模块；
4. **导致高价值 AI/社媒账号批量封号**：数千人共用的免费脏 IP 是 Anthropic (Claude)、OpenAI 与 Google 风控系统的重点打击对象，拿免费节点登录一次付费账号，可能直接引发关联停用。

如果预算确实极度紧张，与其使用来路不明的免费软件，不如选择信息透明的轻量级付费方案（例如年付 ¥79–¥99 档位入门包，或查看[价格与套餐指南](/pricing/)里的低成本试错方案）。

## 四、手机 VPN 与桌面端分平台差异指南

不同操作系统对底层网络接口、商店分发政策及权限管理截然不同，选购与部署前应先了解各平台核心差异：

### 1. Android 安卓平台选型与避坑
- **系统自由度高**：Android 允许直接安装 GitHub 官方开源项目发布的 `.apk` 文件，无需受限于特定地区商店限制；如果使用传统 VPN，也大多能从官网独立下载安装包。
- **主流开源代理方案**：优先选用 **[v2rayNG](/clients/v2rayng/)**、**[FlClash](/clients/flclash/)**、**[Hiddify](/clients/hiddify/)** 与 **[Karing](/clients/karing/)**。
- **高危避坑提醒**：部分软件在 Google Play 上会出现被第三方抢注或替换维护权的同名应用（如 **[NekoBox](/clients/nekobox/)** 官方项目已明确警告**切勿使用 Google Play 版本**）。此外，国产深度定制安卓系统（MIUI/HyperOS、ColorOS、HarmonyOS/OriginOS）普遍具有激进的后台杀进程机制，配置完成后必须手动锁定后台并关闭省电策略，否则锁屏 5 分钟后即断线。

### 2. iPhone / iPad (iOS / iPadOS) 平台选型与避坑
- **商店区域与付费墙**：中国大陆区 App Store 已下架几乎所有代理与主流海外 VPN 应用。需要通过非国区 Apple ID 在 App Store 获取。
- **免费 vs 付费客户端**：主流的 **[Shadowrocket（小火箭）](/clients/shadowrocket/)**、**[Stash](/clients/stash/)** 与 **[Quantumult X](/clients/quantumult-x/)** 均属于美区商店一次性买断付费应用，**[Surge 5](/clients/surge/)** 包含应用内订阅授权；若希望在 iOS 上先用免费合法客户端，可关注 **[Hiddify](/clients/hiddify/)**、**[Karing](/clients/karing/)**、**[Clash Mi](/clients/clash-mi/)** 或官方 **[sing-box (SFI)](/clients/sing-box/)**（实际免费/内购状态以所属地区 App Store 实时展示为准）。
- **iOS 切忌在系统顶栏 iCloud 登录陌生人共享账号**：若被对方开启“查找我的 iPhone”，设备可能被远程锁死。

### 3. Windows 电脑端选型与冲突排查
- **系统代理 vs TUN 模式**：传统 VPN 安装后直接接管全部系统网卡流量；而 Windows 代理软件（如 **[Clash Verge Rev](/clients/clash-verge-rev/)**、**[v2rayN](/clients/v2rayn/)**）默认仅开启“系统代理”，这导致很多独立桌面应用（如 ChatGPT Desktop、Netflix UWP、终端 CLI 工具）可能绕过代理直连。使用这些桌面应用时务必安装 Service Mode 并开启 **TUN 模式**。
- **警惕本地软件冲突**：不要把传统 VPN、游戏加速器和代理客户端 TUN 模式同时打开。

### 4. macOS 苹果电脑端选型要点
- **芯片架构严格区分**：购买 Mac 版 VPN 或下载开源客户端（如 Clash Verge Rev、FlClash、Surge Mac）时，务必先点左上角苹果图标「关于本机」确认自己是 **Apple Silicon（M1/M2/M3/M4 芯片，对应 `arm64`/`aarch64`）** 还是早期 **Intel 芯片（对应 `x64`/`x86_64`）**。
- **系统网络扩展权限**：macOS 初次启用虚拟网卡或增强模式时，必须在「系统设置 → 隐私与安全性」手动点击允许加载对应网络扩展。

## 五、游戏加速器 vs 普通 VPN vs 代理机场：深度场景对比

为什么同样叫“加速器”，游戏加速器却不能当 VPN 用？这源于三者截然不同的服务器部署逻辑：

1. **游戏加速器的工作机制**：游戏加速器厂商在国内各地接入骨干节点，通过专线直连至《Apex Legends》《PUBG》《CS2》《原神国际服》《PSN/Nintendo eShop》等特定游戏服务器所在的海外机房。客户端在 Windows 内核通过驱动钩子（LSP/WFP/NetFilter）**只劫持指定游戏可执行文件（`.exe`）产生的 UDP/TCP 流量**。浏览器、ChatGPT、Netflix 等不在这个游戏进程白名单里的软件，根本不会进入加速器的传输管道。
2. **传统 VPN 为什么打游戏常不如游戏加速器？** 商业 VPN 主要是 TCP/UDP 单隧道转发通用互联网网页，缺乏针对特定游戏服务器端口的动态多路径冗余优化，很多商业 VPN 服务器本身延迟波动大且不支持 FullCone NAT（导致主机联机 NAT 类型变成 Strict 或 Type D 无法组队）。
3. **代理机场可以顺便打游戏吗？** 对于主机商店下载游戏（Switch/PS5 通过软路由或 TUN 代理加速更新）或轻度网页端策略游戏，优质低丢包专线机场（尤其测速图显示 `UDP: FullCone` 的节点，例如 `2026-08-19` 光速云珠海联通 VLESS 测试多数节点显示为 FullCone）表现尚可；但对于毫秒级竞技 FPS 游戏，依然建议搭配专用网游加速器使用，或者分开运行、避免 TUN 冲突。

## 六、传统商业 VPN 常见消费与使用陷阱（购买前必查）

很多刚接触海外网络的用户习惯性在手机商店或搜索引擎搜索“VPN 推荐”，却在购买国际知名商业 VPN 后发现“不仅价格贵，晚高峰还经常连不上、Netflix 照样报错”。原因在于以下四项行业现状：

1. **首月低价诱饵与自动续费暴涨**：不少海外商业 VPN 首页主打“$2.19/月”，但实际上要求一次性预付 2 年（$50–$80 美元），并且到期后按原价 **$12–$15 美元/月** 自动信用卡/PayPal 扣费，国内用户如果忘了取消自动订阅很容易被多扣几百元人民币。
2. **协议特征明显导致的跨境连接失败**：传统商业 VPN 服务器默认面向全球普通商业网络开放 OpenVPN 或标准 WireGuard 端口，在复杂跨境网络环境下经常出现“一直显示 Connecting 却握不上手”或连接 1 分钟后断流的问题。
3. **不支持中国本地生态分流**：由于商业 VPN 的产品假设是“用户人在海外使用全隧道”，因此软件内很少内置完善的 `China GeoIP` 与国内直连白名单。一旦开启，微信发图片、钉钉开会、国内银行 App 和网易云音乐全部被迫绕地球一圈再回来，体验极差。
4. **IP 段公开度过高导致的 AI 与流媒体封控**：由于商业 VPN 的机房 IP 段长期被第三方平台爬虫标记收集，即使成功连上美国节点，打开 ChatGPT、Claude 或 Hulu 时也比优质独立代理线路更容易遇到连续人机验证或直接提示 `Access Denied`。

## 七、五大操作系统下的网络接管与权限机制对比

无论使用传统 VPN 还是代理客户端，各操作系统的底层沙盒规则决定了不同设备上的实际使用边界：

| 操作系统 | 系统级接管接口 | 权限与安装门槛 | 多软件并发与日常注意事项 |
|---|---|---|---|
| **Windows** | WinTUN 虚拟网卡 / WFP 驱动 / 系统代理 (`127.0.0.1:port`) | 安装虚拟网卡服务需一次管理员授权 | 切勿同时开启商业 VPN、网游加速器与代理 TUN 模式；退出软件前确保还原系统代理设置 |
| **macOS** | `NEPacketTunnelProvider` 网络扩展 / 系统代理 | 需在「系统设置 → 隐私与安全性」手动允许扩展 | 严格区分 Apple Silicon (`arm64`) 与 Intel (`x64`) 安装包 |
| **Android** | 系统 `VpnService`（同时仅允许激活 1 个 VPN 应用） | 无需 Root，但需配置电池优化白名单防后台杀进程 | 打开新 VPN/代理时系统会自动顶掉正在运行的另一款；严防第三方应用商店仿冒 APK |
| **iOS / iPadOS** | `NetworkExtension`（仅允许 1 个活跃配置） | 需非大陆区 Apple ID 下载（多数优质规则软件需付费） | 开启「按需连接」可在 Wi-Fi 与蜂窝 5G 切换时无缝自动恢复；严禁系统 iCloud 登录共享号 |
| **Linux / OpenWrt** | `tun0` 接口 + `iptables` / `nftables` (`tproxy` / `redirect`) | 需 `CAP_NET_ADMIN` 权限或路由表管理权限 | 无桌面主机用 v2rayA；OpenWrt 需核对 fw3 vs fw4 防火墙依赖与闪存容量 |

## 八、隐私保护与“零日志”声明的客观边界

无论产品页面把“军事级加密”“零日志（No-Logs）”写得多么动人，具备基础网络常识的用户都应当保持理性边界：
- **加密隧道只保护“您到代理/VPN 出口服务器这一段”**：防止您连接的公共 Wi-Fi 路由器或中间链路看到您在访问什么明文信息；但出口服务器与目标网站之间是否安全，依然依赖目标网站本身是否使用 **HTTPS (TLS)**。
- **不要安装未知服务商提供的根证书（Root CA）**：正规 VPN 与代理协议（WireGuard、VLESS、Trojan、Shadowsocks）在客户端运行时**不需要**往您的系统受信任根证书库里安装自签证书。任何强迫您安装系统级根证书的免费加速工具，都具备解密您 HTTPS 银行与密码流量的技术能力，应当立刻卸载。
- **敏感账号与金融业务保持走直连**：国内网银、支付宝、社保政务、主工作邮箱等服务不要通过海外代理/VPN 访问，在规则分流中保持 `DIRECT` 最安全。
