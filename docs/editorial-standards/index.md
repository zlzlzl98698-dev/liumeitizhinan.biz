# 编辑与实测数据标准

为了避免将品牌方宣传误导为独立实测，本站对所有品牌参数、测速图与流媒体/AI 支持情况执行严格的状态分级：

| 状态标识 | 中文说明 | 数据含义与使用限制 |
|---|---|---|
| `measured` | 本站保留实测截图 | 仅证明截图所示测试日期、测试工具、测试后端及协议下曾获得过对应结果；不代表长期稳定性、所有地区用户体验或未来持续解锁。 |
| `vendor` | 品牌方宣传资料 | 来自品牌官网文案或提供资料中的价格、线路（如 IEPL/IPLC）、不限速或解锁声明，未经本站长期受控复测。 |
| `supplied` | 历史整理供稿数据 | 来自原始整理资料包（例如 2026-10-19 非晚高峰参考测速表），缺乏独立后端截图与控制变量说明，仅供结构化参考。 |
| `historical` | 历史档案记录 | 较早期留存的套餐与入口信息，购买前必须以官网实时页面为准。 |
| `conflict` | 存在数据冲突 | 不同来源或同一份资料的不同段落出现价格、流量、优惠码或链接不一致，本站会并列披露并记录于更正报告。 |
| `not_tested` / `unverified` | 未测试 / 待核实 | 尚未开展独立测试或缺乏原始材料，绝不为了页面美观而虚构测速数字或解锁打勾图标。 |

## 2026-08-11 与 2026-08-19 实测批次与环境规范

- **2026-08-11 测速资料包**：覆盖 17 个品牌（清单记录 16 家 + 压缩包内微风网络截图），尺寸均为 1122×1402 PNG，由 MAI-TEST-BOT 2.0.0-dev（珠海联通 5Gbps）或喵速 4.7.0（珠海联通 9Gbps）生成。图中同时保留 0B、KB 级速度及高延迟节点，未做任何裁剪或美化。
- **2026-08-19 光速云多运营商测试**：覆盖长沙电信、广西移动、河北联通 2Gbps 普通测速及珠海联通 9Gbps VLESS/AnyTLS 基础流媒体与订阅速度测试（共 5 张原图），真实保留香港 OpenAI 仅限 App、新加坡/台湾 YouTube 送中、德国节点降速等实测细节。

## 三项刚性编辑红线（Anti-Hallucination & Compliance）

1. **严禁虚构跑分与主观星级**：所有未开展相同受控测试的品牌，绝不臆造 `4.9/5` 评分、主观排行榜名次或“100% 稳定解锁”承诺；未测试平台一律标注 `not_tested` 或 `vendor`。
2. **冲突原样保留不隐匿**：当多份历史材料针对同一家品牌的月流量（如光速云轻量版 59GB vs 69GB）、优惠码或客户端兼容模式存在差异时，页面内同时并列展示两边口径，并汇总至 [数据冲突记录](/corrections/)。
3. **软件渠道零网盘捆绑原则**：全站 24 款客户端页面严格对照官方开源仓库或官方应用商店指引编写，拒绝提供未知网盘、第三方修改版及未验证直链。
