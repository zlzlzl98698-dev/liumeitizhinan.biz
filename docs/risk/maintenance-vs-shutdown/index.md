# 机场临时维护与停运跑路怎么区分？5 项信号核查与止损替代行动表

**Answer-First 核心结论**：遇到节点全红且主站一度失联，切勿一上来就情绪化认定跑路或听信陌生人群里转发的未经证实小道消息。**真停运与普通临时维护/域名屏蔽的本质区别**，体现在 **5 项可验证工程信号** 中：① **官方防失联页与通知频道是否仍在发声更新**；② **订阅 URL 是彻底被注销（DNS `NXDOMAIN` / HTTP 404）还是仅前端网页遇防火墙拦截**；③ **是全地区全节点同时掉线还是仅单条国内入口波动**；④ **失联持续时间是否超过 3–7 天无任何技术恢复动作**；⑤ **事发前是否有反常超低价甩卖长期终身套餐行为**。核查确认属长期停运风险后，再按冷静方案平滑切换替代服务。

## 一、快速鉴别对照表：临时波动 vs 疑似长期停运风险

在作出决策前，请逐项对照下面 5 个可观察事实，**严格区分“已证实官方通知/客观报错”与“外界猜测情绪”**：

| 核查信号维度 | **大概率是临时维护 / 域名屏蔽 / 本地异常** | **高风险：疑似长期停止运营 / 跑路预警** |
|---|---|---|
| **1. 本地排查对比结果** | 先用手机 5G 热点测或更新一次订阅，部分或全部节点能换新入口恢复；[节点超时 7 步排查](/troubleshooting/all-nodes-timeout/) 发现系本机问题 | 跨电信/移动/联通 5G 不同网络及境外直连环境全测均持续无任何节点响应 |
| **2. 备用网址与防失联渠道** | 主域名打不开，但品牌当初提供的永久发布页、邮箱公告或官方通知频道仍在更新新域名或维护通告 | 主官网与所有官方发布页连续多日不可达（或被清空）、客服渠道长期失联、公告渠道已彻底解散或禁言删库 |
| **3. 订阅接口 HTTP 特征** | 原订阅地址拉取失败后，通过备用入口可拿到刷新后的有效新节点 IP 配置 | 托管订阅域名本身解析失败（`NXDOMAIN`）或持续多日返回服务器彻底关机超时（非单日临时 CDN 波动） |
| **4. 故障时长与响应特征** | 一般在 **数小时至 1–2 天内** 陆续看见部分核心区域（港/日/新）先恢复通畅 | 超过 **5–7 天以上** 没有任何可证实的技术恢复进展或工单人员响应 |
| **5. 异常前兆背景对照** | 平时价格秩序正常、无端突然波动属正常攻防周期调整 | 停服前突击开启“全场一折终身永久包”“充 500 送 1000”等不合常理的清仓吸金促销（详参 [避坑特征指南](/risk/avoid-pitfalls/)） |

## 二、发现疑似长期异常后的 4 步冷静自保动作

1. **第一步：第一时间先排查自己本地，别误伤正常老机场**
   在确认任何外部故障前，请先确保已经完成了 [节点全部超时排查](/troubleshooting/all-nodes-timeout/) 与 [Wi-Fi vs 5G 对比排查](/troubleshooting/wifi-vs-cellular/)：校准电脑 UTC 时间、关掉本机代理尝试更新订阅一次，确认不是因为自己电脑忘了更新中转域名。
2. **第二步：留存账户与付款凭证（仅作自查与申诉备档）**
   如果确认官网长期失联且无公告，请将此前的 **支付宝/微信账单商户订单号、官网注册邮箱与最近一次购买记录截图** 保存在本地文件夹（详细指引见 [账号与退款规则专题](/risk/account-and-refund/)）。虽然跨境服务极难事后追讨，但保留原始交易凭据能帮您清晰复盘或配合对应支付平台风控举报异常商户（若发现对方涉欺诈吸金）。
3. **第三步：立刻停止在该未知归属面板或可疑接盘弹窗里再次充值**
   当原机场疑似跑路时，市场上最容易出现“假冒官方恢复公告、要求原用户重新充 ¥30 激活账号迁移新站”的二次收割骗局，**切勿因想捞回旧余额继续往来路不明的新链接付钱**！
4. **第四步：启用备用小流量方案，并调整日后购买结构**
   重要工作用户日常务必建立 **“1 家主力月付/半年付 + 1 家百元不限时小备胎（如光速云 ¥147/247G、星岛梦 ¥100/100G 或二猫云 ¥99/100G，前提各自独立运营实体非同系马甲）”** 的双线架构：即便主线发生突发维护几天不能用，切换到副线就能保证核心办公和紧急通信一分钟都不中断。

## 三、重建安全选型基线（从根源降低中招概率）

当您准备重新挑选服务时，按以下 4 条纪律过滤新候选品牌，可参照 [服务异常后平滑替代方案总览](/risk/alternatives/)：
1. **看重长记录与独立透明证据**：优先考量标注运营时间较久（如 2020–2023 年档）、敢于留存带工具时间戳和缺点说明实测原图的品牌（可对比 [独立品牌深度评测中心](/reviews/)）；
2. **坚持低试错上限**：前两个月严守 **月付机制**，拒绝一上来被“年付只要几块钱一个月”推销诱惑重仓锁单（原因见 [新手机场首单月付 vs 年付对比](/recommend/monthly-vs-annual-first-buy/)）；
3. **鸡蛋别全放在关联马甲里**：如资料中已核对出的同系关联品牌记录，避免拿同体系里的两家互相做容灾备用；
4. **把订阅通用性留给自己**：尽量选择支持导出 Clash / Shadowrocket 通用订阅的方案，避免因某家客户端无法运行或失联导致连客户端软件都彻底失效。
