# 机场服务异常与停止运营后的平滑替代方案

**Answer-First 核心结论**：面对在用机场突发停服失联、晚高峰持续恶化、或因专属客户端限制无法适配软路由/AI 精细分流时，最有效的应对不是病急乱投医再去搜未知的免费节点，而是执行一套标准的 **“① 立即清理失效代理与留存凭证 → ② 启用备用不过期包顶上 → ③ 按‘通用订阅 + 月付试错 + 实测档案’标准从品牌库筛选主力替代 → ④ 建立主备异构防断联结构”** 迁移流程。

## 二、服务失联后的 24 小时平滑切换 SOP（4 步执行）

1. **第 1 步（止损与清理本地残留，5 分钟）**：
   - 关闭旧代理软件的「系统代理」与「TUN 模式」开关，确认国内网站（如百度/微信/淘宝）恢复秒开；
   - 如果旧服务使用的是某家专属独立 App 且确认不再续用，直接卸载并检查 Windows 网络代理设置是否已重置为关闭；
   - 保留旧服务商最后一次付款账单及注册邮箱截图记录，以备日后核对或工单追索。
2. **第 2 步（部署通用客户端，10 分钟）**：
   - 趁着换机场的契机，强烈建议电脑装 **[Clash Verge Rev](/clients/clash-verge-rev/)**（或 [v2rayN](/clients/v2rayn/)），Android 装 **[v2rayNG](/clients/v2rayng/)** 或 **[FlClash](/clients/flclash/)**，iPhone 装 **[Shadowrocket](/clients/shadowrocket/)**（或免费版 [Hiddify](/clients/hiddify/)）。学会用通用客户端后，以后一辈子换机场都只需要换一条订阅链接，不再被任何单一服务商绑架。
3. **第 3 步（筛选对比并购买单月主力，10 分钟）**：
   - 在 **[品牌多维对比中心 →](/compare/)** 勾选 2–3 家候选品牌对比月付价格、线路与客户端支持；
   - 点击档案页官方入口下单 **1 个月最小可用档**，复制通用订阅导入客户端，按 [TUN 与防泄漏指南](/guides/tun-and-dns/) 关闭 IPv6 并锁定 AI 固定单节点。
4. **第 4 步（配置第二家备用不过期包，建立长期双保险）**：
   - 首月主力稳定跑通后，建议花 ¥100–¥147 购入另一家完全不同品牌的一次性不过期流量包，作为第二个 Profile 保存在客户端中。平时用主力，主力一旦维护或波动，3 秒切至备用包零中断衔接。
