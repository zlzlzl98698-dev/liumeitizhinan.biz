# OpenWrt 24.10 安装 Nikki 透明代理与 fw4 防火墙依赖配置指南

**Answer-First 核心结论**：在 **OpenWrt 24.10+** 新一代路由器固件生态中，**Nikki** 是替代复杂传统插件的轻量化 **Mihomo 透明代理首选方案**。

实施前必须确认以下 **3 个刚性前置门槛**：
- **固件与防火墙门槛**：**系统必须处于 `OpenWrt 24.10` 及以上官方或干净源码构建版**（原生基于 `fw4 / nftables` 防火墙，切忌强塞进老旧 fw3/iptables 魔改固件）。
- **订阅与内核步骤**：**机场必须支持第三方 Clash YAML 订阅导出**；安装包须按官方仓库 Release 补齐语言包与 `mihomo` 内核依赖，再配 **订阅自动更新 + Fake-IP DNS 劫持 + 局域网绕过策略**。

---

## 一、装前核查：你的软路由与机场条件满足吗？

| 前置检查项目 | 必须达到的硬性条件 | 不达标时的正确替代方案 |
|---|---|---|
| **固件底层版本** | 必须为 **OpenWrt 24.10+**（含 `firewall4 / nftables` 支持） | 若您正在跑 OpenWrt 21.02/22.03/23.05 老版本不愿重刷，改看 [OpenClash](/clients/openclash/) 或 [PassWall2](/clients/passwall2/) |
| **硬件架构与存储空间** | 确认路由 CPU 架构（如 `x86_64`、`aarch64_cortex-a53`），`overlay` 可用空间建议 ≥ **40MB** | 如果硬路由只有 16MB 闪存装不下 `mihomo` 二进制大文件，请外接 U 盘扩容或作为旁路由部署在 x86 小主机上 |
| **机场订阅类型** | 必须能拿到 **Clash YAML 或标准通用订阅 URL**（如光速云、星岛梦等） | 若买的是飞猫云、隐形人等纯专属客户端盘，**放弃软路由想法或先换可导出订阅机场** |

## 二、标准安装与依赖核对步骤（告别装完报错缺少模块）

在官方开源仓库获取对应自己路由器 CPU 架构的 `luci-app-nikki` 与 `nikki` 主包（完整说明与仓库索引原则见 [Nikki 客户端百科页](/clients/nikki/) 与 [OpenWrt 平台全览](/clients/openwrt/)）：

1. **安装前更新软件源缓存（确保 `fw4` / `kmod-nft-tproxy` 等内核模块可用）**
   通过 SSH 连入 OpenWrt 终端执行基础更新，确认本地能正常安装内核级透明代理模块：
   ```sh
   opkg update
   ```
   *(若使用更新的 OpenWrt `apk` 包管理器架构版本则执行 `apk update`。)*
2. **确认必需的防火墙与网络依赖包**
   根据透明代理运行模式（推荐 `TProxy` 或 `TUN`），系统通常需要具备如下核心基础设施组件（正式版安装脚本一般会自动拉取，手工排查缺包时重点核对）：
   - `firewall4` / `nftables`（OpenWrt 24.10 默认核心，**不要为了老教程强行删 fw4 换回 fw3**）；
   - `kmod-nft-tproxy`（支持 TCP/UDP 透明代理拦截）或 `kmod-tun`（TUN 模式必需）；
   - `ca-bundle`、`curl`（确保路由器能正常验证 HTTPS 证书并发起订阅拉取）。
3. **上传安装主程序与 LuCI 中文界面**
   依次安装核心程序包（`nikki`）、内核主程序与界面汉化包（`luci-app-nikki` 及中文语言包）。安装完毕后刷新路由器管理后台 `http://192.168.x.1` 左侧「服务（Services）」菜单即可见到 `Nikki` 入口。

## 三、配置文件订阅导入与防 DNS 泄漏基础设定

进入 LuCI →「服务 → Nikki」界面，按以下顺序初始化首次上线：

### 1. 导入订阅与配置文件（Profile）
- 点击进入 **「配置 / 订阅（Profiles）」** 管理页；
- 粘贴支持通用订阅的机场提供的 Clash 订阅链接，设定订阅更新周期（建议 `12 小时` 或 `24 小时`），保存并点击一次「更新」；
- 如果路由器当前处于断网无法拉取海外被屏蔽托管站的状态，先在电脑下好离线 `.yaml` 文件通过网页上传导入，或者暂时借助手机热点连上一次拉完列表即可。

### 2. 开启 Mihomo 混入（Mixin）覆写：稳住 DNS 与分流安全
全屋流量的安全性全在路由器端，务必检查开启关键 Mixin 参数：
1. **代理模式保持 `Rule`（规则模式）**：切勿开 Global，防止全家看爱奇艺、下载系统更新时把宝贵的海外月流量全刷光（参考 [300GB 与 500GB 软路由损耗控制](/pricing/300gb-vs-500gb/)）。
2. **开启 Fake-IP 与 DNS 劫持**：确保路由器接管局域网设备下发的 `53` 端口 DNS 查询请求，让国内域名走 ISP/阿里/腾讯 DoH 快速直连，海外流媒体与 AI 域名全部加密发往机场节点解析，彻底杜绝家里电视盒出现 `YouTube 送中`。
3. **禁用或慎重配置 IPv6 代理转发**：如果您的宽带拨号下发了原生 IPv6 地址且机场仅支持 IPv4 出口，务必在路由侧妥善屏蔽海外站点的 IPv6 AAAA 回传，防止家里设备跳过路由器代理直连导致 Netflix/ChatGPT 定位暴露（排障原理见 [TUN 与 DNS 防泄漏指南](/guides/tun-and-dns/)）。
4. **勾选“绕过中国大陆 IP”与常见私网段**：保留 `192.168.0.0/16`、`10.0.0.0/8` 直连，保证内网 NAS 访问、打印机及路由器自身通信零阻滞。

## 四、如何验证安装彻底成功并避免日常卡顿？

1. **看状态与实时日志**：在 Nikki 主页点击「启用并保存应用」，确认「核心运行状态」为绿灯 `Running`；打开内置 Yacd / Metacubed 控制面板，测试主力港/日/新节点延迟正常；
2. **在局域网手机/电视测试内外双通**：关闭手机端所有本地代理 App，只连路由器 Wi-Fi：
   - 打开国内测速或百度应秒开且显示本地真实宽带城市归属；
   - 打开 YouTube 4K 验证左上角显示 `HK`/`JP` 非 CN 且码率顺利爬升；
3. **防高风险单节点拖垮全屋**：如果您选用的订阅里偶尔出现类似 DE01 掉速至 40KB/s 的单点故障，在软路由侧利用策略组正则把主力节点限制为经过验证的稳定港/日/新骨干，并配合 [Claude 锁节点技巧](/guides/claude-fixed-node-rules/) 为家里电脑上的 AI 工作流单独锁定纯净美国或新加坡出口。
