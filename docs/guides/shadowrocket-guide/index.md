# iPhone Shadowrocket 小火箭添加订阅、按需连接与流媒体/AI 分流完整教程

**Answer-First 核心结论**：**Shadowrocket（俗称“小火箭”）** 是 iPhone 与 iPad 生态协议兼容最全的第三方客户端，支持 Shadowsocks、VMess、VLESS（含 Reality）、Trojan、Hysteria 2 等主流协议。

核心配置与安全原则浓缩为以下 **3 句话**：
- **账号获取安全**：使用自己的外区 Apple ID 从 App Store 购入正版，绝不向系统 iCloud 登录陌生共享账号。
- **订阅与全局路由**：从支持通用订阅的机场后台复制链接添加为 Subscribe 订阅并打开自动更新；首页「全局路由」保持在 **配置（Config）**，选中节点开启即可国内直连、海外分流。

---

## 一、获取前必须重视的安全红线与适用品牌边界

### 1. 绝不登录陌生共享 Apple ID 到设备“设置”
网络上常见各种“1 元租美区 ID 下载小火箭”广告。iOS 设备如果按卖家指引在手机主「设置」顶部登录了他人账号，对方可以通过“查找我的 iPhone”直接远程锁死你的整台手机进行勒索。
- **正确做法**：自己用国内手机号/邮箱注册一个美区或港区 Apple ID（或仅在 **App Store** 商店内登录已信任的家人账号并确保**绝对不开启 iCloud 同步与查找**），购买正版（USD $2.99）后立即退回自己主号或长期自持独立美区号。

### 2. 确认您买的机场提供外部订阅链接
如果您的主力品牌是飞猫云、SOGO 云、全球云、隐形人、灵猫网络、闪跃等纯专属客户端品牌，它们不提供通用订阅，您在 iOS 上通常需按官网指引安装其专属端（或企业签 TestFlight 客户端），无法直接往 Shadowrocket 填入订阅链接。而 **光速云、星岛梦、梯子云、唯兔云、一翻云** 等保留通用订阅的服务商则均可直接导入小火箭。

## 二、4 步完成订阅导入与初次连接

1. **复制订阅链接**：在 Safari 登录您的机场控制面板，找到「复制订阅链接」或「导入 Shadowrocket」（若按钮直接呼出小火箭弹窗，点允许跳转即可；否则复制 URL 手动添加）。
2. **添加 Subscribe 订阅节点**：
   - 打开 Shadowrocket 首页，点击右上角 **`+`** 号；
   - 第一行「类型」保持默认 **`Subscribe`**（不要错选成单一节点协议）；
   - 将剪贴板里的 URL 粘贴进 **`URL`** 栏位，在「备注」填上便于识别的名字（例如机场品牌名称）；
   - 点击右上角 **「完成」**。软件会自动开始第一次拉取节点列表。
3. **开启自动更新与时间显示**：
   - 点击底部导航栏最右侧 **「设置」→「订阅」**；
   - 打开 **「打开时更新」** 开关，并酌情开启「自动后台更新」（这样当机场更换域名入口时，不必手动删掉重导）。
4. **设定全局路由与首次 VPN 授权**：
   - 切回底部最左侧 **「首页」**；
   - 找到 **「全局路由（Global Routing）」**，点击进去确保选中 **「配置（Config）」**；
   - 点击「连通性测试」，等待节点右侧出现绿色数字（如 `86ms`），点选一个稳定节点（看港台剧选香港/台湾，用 ChatGPT/Claude 优先选美国/日本/新加坡）；
   - 打开最上方总开关，系统首次弹出 `“Shadowrocket”想添加 VPN 配置`，点 **Allow（允许）** 并验证 Face ID / 锁屏密码即完成连接。

## 三、进阶设置：配置“按需连接”与防止 IPv6 泄漏

### 1. 用“配置（Config）”替换默认懒人规则，减少微信卡顿与国内走代理
打开底部 **「配置（Config）」** 标签，您可以看到当前激活的分流规则（默认 `default.conf` 已带基础绕过大陆 IP 规则）。若您发现偶尔访问某些国内 App 变慢，或希望为 ChatGPT/Claude 添加专门域名规则：
- 可以在配置界面查看当前分流策略组，确保 `PROXY` 之外的 `DIRECT` 规则优先匹配中国大陆常见域名段（`GEOSITE,CN` / `GEOIP,CN`）；
- 若频繁在特定流媒体或 AI 软件遇错，可在配置编辑中确认 **DNS 覆写** 使用可信 DoH 解析，避免本地运营商 DNS 污染导致域名解析偏离。

### 2. 开启“按需连接（On Demand）”，省去每次手动开关麻烦
点击底部 **「设置」→「按需连接」**：
- 可以设定当您连上家里配置好 OpenWrt 旁路由/软路由的特定家庭 Wi-Fi SSID 时，小火箭**自动断开**（避免手机在网关内二次代理耗电）；
- 而一旦走出家门切换回蜂窝 5G 网络或其他公共 Wi-Fi 时，小火箭**自动秒连**保护流媒体与 AI 访问。

### 3. 排查小火箭常见的 3 类异常
- **连接后网速极慢或 ChatGPT App 仍提示区域不可用**：进小火箭「设置 → 代理 → 代理类型 / DNS」，若当地移动宽带分配了激进的 IPv6 地址且机场节点不支持 IPv6 穿透，进入「设置 → 按需/网络」或本地规则中确认 **关闭 IPv6 支持**（详见 [IPv6 泄漏排查手册](/troubleshooting/ipv6-leak-error/)）。
- **只显示 1 条空白节点或提示超时**：检查顶部状态、确认订阅流量未用完，以及手机「设置 → 通用 → 日期与时间」开启「自动设置」（系统时间误差 > 90 秒会导致 VLESS/Trojan 握手全部超时）。
- **连接开关反复弹出权限弹窗或断连**：检查手机内是否同时开了多款加速器或公司 MDM VPN（同一时刻 iOS 只允许一个网络扩展接管流量），彻底关掉其他 VPN 再试。

### 4. 常见异常症状与排查对照表

| 异常症状 | 常见诱因 | 对应排查与设置路径 | 注意事项 |
|---|---|---|---|
| 节点全部超时 / 只显示 1 条空白节点 | 系统时间偏差 > 90 秒、流量耗尽或开着代理刷新 | 开启系统「自动设置日期与时间」；关闭总开关直连刷新订阅 | 确认机场非纯专属客户端（支持通用订阅） |
| 微信卡顿 / 国内 App 变慢 / 耗电高 | 全局路由误选「代理（Proxy）」或家里 Wi-Fi 二次代理 | 首页「全局路由」固定为「配置（Config）」；设置家庭 Wi-Fi 按需断开 | 确认 `GEOSITE,CN` / `GEOIP,CN` 优先匹配 `DIRECT` |
| 连上后 ChatGPT App 仍报地区不可用 | 国内 5G/宽带分配 IPv6 未被节点接管导致泄漏 | 进入设置关闭 IPv6 支持，并在配置中确认 DoH 解析正常 | 同时检查是否误选了受限地区节点 |
| 开关反复弹窗或频繁断开 | 手机同时运行多款加速器或公司 MDM VPN | 关闭其他 VPN 应用，仅保留 Shadowrocket 网络扩展 | iOS 同一时间仅允许单一网络扩展接管流量 |
