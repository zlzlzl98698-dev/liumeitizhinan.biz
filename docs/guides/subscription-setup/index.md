# 机场订阅链接如何使用？获取、分辨格式、安全导入与自动更新全流程指南

**Answer-First 核心结论**：拿到机场套餐后，第一步是确认品牌采用的是 **通用订阅导入模式**（如光速云、星岛梦、梯子云、唯兔云等），还是 **官方专属客户端模式**（如飞猫云、隐形人、SOGO 云等，直接下载官网 App 账号登录，无订阅链接）。支持通用订阅的设备只需 **4 步即可通网**：① 从官网面板复制对应客户端类型的订阅 URL → ② 打开第三方客户端粘贴导入并设置 12–24 小时自动更新 → ③ 将代理模式保持在 **规则模式（Rule）** → ④ 执行延迟测速并挑选港/日/新/美节点开启连接。

---

## 一、导入前必查：您的品牌属于哪一种接入机制？

很多新手花半小时在网站后台乱找“Clash 订阅链接”，最后发现根本找不到——其实是因为现在市面上的服务商明显分为两大技术阵营：

| 接入模式 | 典型代表品牌 | 正确上手方式 | 能不能用 Clash / 小火箭 / 软路由？ |
|---|---|---|---|
| **通用订阅 + 自研双支持（或纯通用订阅）** | 光速云、星岛梦、小明Cloud、一翻云、极连云、光年梯、梯子云等 | 在后台点击「复制订阅」或「一键导入」到第三方客户端；嫌麻烦也可用其自研端 | **可以**，支持 Windows/macOS/iOS/Android/Linux/OpenWrt |
| **纯专属客户端（无订阅 URL）** | 飞猫云、SOGO 云、全球云、隐形人、闪跃、灵猫网络、Firefly、无忧链接（2026-10起） | 下载官网提供的客户端安装包，输入注册邮箱和密码直接登录开关连接 | **不可以**，不提供链接，无法导入外部第三方软件或软路由 |

> **重要提示**：如果您正准备入手且日后有使用 OpenWrt 软路由或定制分流计划，务必优先阅读 [光速云 vs 飞猫云深度对比](/compare/guangsu-vs-feimao/) 或 [选机场核心指标判断](/recommend/how-to-choose/) 核对清楚客户端策略。

## 二、分辨两种常见的订阅链接格式：Clash YAML vs Base64 通用订阅

复制机场后台给出的订阅链接时，很多面板会提供多个按钮（或只有一个自适应 URL）。两者的本质区别在于服务端返回的数据结构：

1. **Clash / Mihomo 配置文件格式（`.yaml`）**
   - **适用软件**：Clash Verge Rev、FlClash、Clash Nyanpasu、Mihomo Party、Clash Meta for Android、Stash（iOS）、OpenClash / Nikki（OpenWrt）。
   - **特点**：配置文件中**已经包含了服务器节点 + 现成写好的分流规则（哪些域名直连、哪些走代理、哪些走广告拦截）**，导入后即可直接使用 `Rule` 规则模式。
2. **Base64 / V2Ray / sing-box 通用节点清单**
   - **适用软件**：v2rayN（Windows/macOS/Linux）、v2rayNG（Android）、Shadowrocket（iOS）、Hiddify、Karing、sing-box 原生端。
   - **特点**：大多只包含纯粹的节点服务器参数，分流规则通常由客户端本地内置路由规则（如 Shadowrocket 选配懒人配置或 v2rayN 内置绕过大陆规则）接管。

> **为什么尽量别拿订阅链接去陌生网站做“在线订阅转换”？**  
> 现在的 Clash Verge Rev、Karing、Hiddify、Shadowrocket 均自带极强的多协议自适应解析能力，**绝大多数面板直接给出的自适应订阅或 Clash 订阅已无需第三方网站中转**。把含 Token 的完整链接粘贴进不明公益转换站，极易造成 Token 泄露与流量被他人盗刷（安全详情请看 [订阅转换站泄露风险指南](/risk/subscription-converter-risk/)）。

## 三、分平台标准导入操作全流程

### 1. Windows / macOS / Linux（以 Clash Verge Rev 为例）
1. 在官网选择「复制 Clash 订阅」或「复制通用订阅」。
2. 打开 [Clash Verge Rev](/clients/clash-verge-rev/)，点击左侧导航栏的 **「订阅 / Profiles」**。
3. 在顶部输入框粘贴订阅地址，点击右侧 **「导入 / Import」**。
4. 导入成功后会出现新的配置卡片：右键该卡片 → **「编辑信息」**，将更新间隔设为 `720` 分钟（12 小时）或 `1440` 分钟（24 小时），**确认勾选启用该配置（卡片高亮）**。
5. 切回 **「代理 / Proxies」** 确认顶部模式为 **规则（Rule）**，对节点列表点击测速图标（闪电图标）筛选可用低延迟节点，最后到 **「设置 / Settings」** 打开「系统代理」（桌面聊天软件和终端还需开启 **服务模式 + TUN 模式**，详见 [Clash Verge Rev 完整实战教程](/guides/clash-mihomo-guide/)）。

### 2. iPhone / iPad（以 Shadowrocket 小火箭为例）
1. 从外区 App Store 下载正版 Shadowrocket（切忌轻信免费网盘共享账号以防锁机）。
2. 在机场面板选择「复制 Shadowrocket 订阅 / 通用订阅」。
3. 打开小火箭首页，点击右上角 **`+`** 号 → 类型保持 **Subscribe（订阅）** → 在 `URL` 栏粘贴订阅链接 → 填写好辨识度高的备注名称 → 点击右上角 **「完成」**。
4. 到小火箭底部 **「设置」→「订阅」**，打开 **「打开时更新」与「自动后台更新」** 开关，确保机场换入口后能自动跟进。
5. 返回首页，将「全局路由」设置为 **「配置（Config）」**，选中任意绿色延迟正常的港/日/新节点，打开最顶部连接开关，首次弹窗输入手机解锁密码同意添加 VPN 描述文件即可上网。详尽图文思路请参考 [Shadowrocket 小火箭完整教程](/guides/shadowrocket-guide/)。

### 3. Android 安卓端（以 v2rayNG 或 FlClash 为例）
- 若使用 **FlClash / Clash Meta for Android**：操作与桌面版一致，在「配置 / Profiles」点 `+` → 从 URL 导入。
- 若使用 **v2rayNG**：点击左上角三道杠菜单 → **「订阅分组设置」** → 右上角 `+` → 粘贴地址并填写备注保存 → 回到首页点击右上角 `⋮` → **「更新订阅」** → 右下角测真连接延迟，再选中节点点底部开启图标。

## 四、导入成功后的 4 项安全与稳定性验证习惯

1. **先做真连接（URL Test）再判断可用性**：不要看静态列表以为导入完了就能用，必须触发一次测速看到具体毫秒数（如 `45ms`、`120ms`）才说明节点处于可达状态。
2. **用浏览器访问非缓存测试页验证规则分流是否生效**：
   - 打开百度或高德地图确认国内直连速度正常（证明没开成“全局代理”拖慢国内网）；
   - 访问 `https://www.google.com` 或 YouTube 验证海外通道正常。
3. **订阅更新按钮失败不要急着删配置**：在尝试更新订阅之前，如果当前代理已经全红失效且勾选了「通过代理更新」，请先临时取消代理或关掉系统代理，直连更新（因为被墙了的中转有时需要直连拉或通过备用节点拉取，详看 [订阅更新失败排查](/troubleshooting/subscription-update-failed/)）。
4. **绝不对外公开截图中暴露的完整订阅 URL**：截图求助他人或发往工单时，务必将 `token=xxxx` 部分彻底打码遮挡。
