# 推广链接与利益关系披露

流媒体指南（`liumeitizhinan.biz`）通过提供免费的流媒体排障教程、AI 网络知识库与客户端配置文档获取自然搜索流量，并在机场品牌评测、价格对比与推荐页面中嵌入部分服务商的联盟注册入口。

## 我们的商业透明承诺

1. **统一标记属性**：本站所有机场推广注册链接均统一读取自结构化数据库 `data/brands.json` 与 `data/affiliate-links.json`，并在 HTML 输出中严格添加 `target="_blank" rel="nofollow sponsored noopener"`，全站自动化审计确保零漏标。
2. **不影响用户价格**：通过本站推广链接注册或使用站内收录优惠码，不会增加您的支付价格；部分优惠码可帮助新用户获得首单折扣（实际折扣以官网结算页实时生效为准）。
3. **独立评测与缺点披露**：商业合作关系不会导致本站隐藏套餐限制（例如一次性流量包与月付重置的区别、不支持退款提示、专属客户端无法导入 Clash、或者实测中出现的送中与风控限制）。
4. **纯档案品牌无假跳转**：对于未收录公开注册入口的品牌（如快狸），本站仅保留纯档案与实测截图，不设置虚假跳转链接。
5. **排序依据可核查**：首推测试样本（如光速云）基于其拥有跨三网 `2026-08-19` 五张原图、双端兼容与明确短板披露，排序优先展示信息完整度，**不代表任何绝对商业排名或付费买榜**。

## 商业利益隔离与读者核查建议

- **先月付验证**：无论任何服务商是否含推广链接，均建议先以单月最小流量包（¥15–¥25 区间）在个人常用运营商（电信/联通/移动）晚高峰验证 7 天，确认无频繁断流后再评估半年/年付；
